# NexyFab 정교화 구현계획 — 코퍼스 환류 (260718 수립)

## 배경·목표

MDS-2500 SWRO 생성 테스트(56부품·간섭 0)로 실증된 격차: 참고파일(실물 CAD)은 피처 수준
디테일(플랜지 볼트·캐스터 포크·경판 곡률·엘보 R)을 갖지만, 생성물은 프리미티브 조합 수준.
원인 = 코퍼스 환류가 **거친 입자(유형→템플릿 33종·부품 27종)까지만** 되어 있고,
피처 수준은 임포터가 배치용 AABB 근사만 뜨는 설계라 어휘로 되돌아오지 않음.

**목표: "구매품은 실물급, 구조물은 생성" — 생성물이 코퍼스 수준 정교함에 수렴.**

## 불변 원칙

- 날조 금지: 디테일 치수는 코퍼스 **실측 보정 상수**(수치 테이블)로만 — 추정은 명시
- GrabCAD 코퍼스 = 로컬 전용: **기하 복사·산출물 삽입 금지**, 실측 비례로 클린룸 재구현만
- 생성≠검증: 모든 매크로·배관은 기존 게이트(간섭 0·부유 0·치수 폐형) 통과 필수
- 각 Phase 완료 기준: SWRO 벤치(동일 사양판 입력) before/after + 게이트 0/0 + vitest

## Phase 1 — 기존 기능 총동원 (즉시, 1~2일)

1. **배관 라우터 표준화**: 어셈블리 스펙 pipes(경유점 라우팅) 사용을 생성 표준으로 —
   수동 원통 배치 금지. 엘보 곡관 자동 생성 확인. SWRO 재생성으로 검증.
2. **revolve 어휘 적용**: 탱크 경판(2:1 타원 — pressure_vessel 템플릿 로직 재사용),
   펌프 볼류트, RO 端경판. 계단식 실린더 스택 대체.
3. **GA_3D PBR 렌더**: html-render.mjs — metalness/roughness + 환경맵 + 그림자 + ACES
   톤매핑. 형상 불변·체감 정교함 최대 상승의 저비용 항목.

## Phase 2 — 디테일 매크로 5종 (코퍼스 실측 보정, ~1주)

매크로 = **프리미티브 묶음을 방출하는 조립 함수**(커널 무변경 → 게이트·물량 그대로 적용).

| 매크로 | 구성 | 도너(실측 근거) |
|---|---|---|
| caster_assembly | 휠+포크 2판+상판+스위블/리지드 | caster-wheel-5-inch(참고파일들4 — IGES 트림곡면 해소 후 실측, 폴백=5" 카탈로그 관례) |
| flanged_nozzle | 노즐관+플랜지판+볼트원(hex_bolt 재사용) | flanged-elbows STEP — **실측 완료: 레그≈1.6D·중심선 R≈1.1D** |
| pipe_elbow / tee | 3분할 각도 세그먼트 근사+플랜지 옵션 | 동상 |
| cabinet_detail | 문 분할선(얕은 홈)+힌지 블록+루버 슬릿+명판 | electrical-cabinet-21(x_t 파싱 가능) |
| instrument_set | 게이지 다이얼+니플, 밸브 핸드휠 | gate_valve 템플릿 축소 재사용 |

- 보정 상수는 `scripts/drawing-to-3d/detail-calibration.json`(수치만 — 기하 없음=라이선스 클린)
- 매크로별 셀프테스트(치수 폐형) + SWRO v8 적용 시 간섭 0 유지

## Phase 3 — 포트 자동 배관 (~1-2주)

- 부품·템플릿에 `ports[]` 메타(위치·구경·계통·방향)
- 라우터 확장: 포트-투-포트 맨해튼 경로 + 장애물(부품 AABB) 회피 + 엘보 자동 삽입 +
  지지 슈 자동 배치(스팬 초과 시)
- 게이트 보완: 노즐 접속부 배관-장비 접촉은 선언 체결로 인정

## Phase 4 — IGES 트림곡면 + 실측 파이프라인 (병행)

- IGES 144(트림곡면)·128 NURBS 좌표 발산 수정(캐스터 도너 실측 1e23 발산 실증) →
  잔여 도너 개방
- 채굴 스크립트: 도너 폴더 → 원통Ø·AABB·부품수 통계 → 보정 상수 테이블 자동 갱신

## Phase 5 — 혼합 어셈블리 (실물 STEP 삽입, ~2-3주)

- to-step: replicad importSTEP → 생성 B-rep와 컴파운드 병합(변환 배치)
- 어셈블리 스펙 `{type:'import', file, at}` 부품 — **사용자 소유/자유 라이선스 파일만**
  (GrabCAD 코퍼스 삽입 차단 게이트)
- 뷰어·GA·BOM에 임포트 부품 구분 표기

## Phase 6 — 필렛/모따기 패스 (마감)

- to-step OCCT fillet: 프레임 모서리·플레이트 에지 선택 필렛(옵션) —
  실패 시 무필렛 정직 폴백

## 벤치·검증

- 고정 벤치 = MDS-2500 SWRO(사양판 입력 동일) — Phase마다 렌더 비교 저장
- 회귀 = 기존 셀프테스트 33종 + 배터리 44 + brep 648 유지
