# NexyFab 실시설계 수준 도달 계획 (260718 수립 · 260718 기준 확정)

## 합격 기준 (사용자 확정)

> **참고파일들(코퍼스) 수준의 2D 도면이 나오고, 그 도면만으로 실시(제작 착수)가 되는 것.**

즉 산출 도면을 코퍼스의 실제 실무 도면 옆에 놓았을 때 표현 체계가 대등해야 하고,
제작사가 추가 질의 없이 발주·가공에 들어갈 수 있어야 한다.
법정 경계(불변): 인허가 제출 도서는 유자격 기술사 날인 영역 — 본 파이프라인은
"제작용 실시도서 + 검토용 계산서(비법정 명시)"까지를 담당한다.

## 도면 완성도 체크리스트 (코퍼스 40본 실측 기반 — 자동 게이트화 대상)

각 도면 시트가 아래를 충족해야 "코퍼스급" 판정. `drawing-completeness` 게이트로
자동 검사(누락=정직 경고 목록):

| # | 항목 | 코퍼스 근거 |
|---|---|---|
| C1 | 도곽+표제란(도번·축척·리비전·시트 n/N) | 전 도면 공통(title 블록) |
| C2 | 3면도 + **단면도(해칭)** ≥1 | HATCH 850회/40본 — 단면 표현 상용 |
| C3 | 부분 상세 콜아웃(원+지시선, 확대 스케일) | 기계 도면 관례 |
| C4 | 치수: 체인/누진 + ⌀·R 기호 + 공차 표기(주요 치수) | DIMENSION 1,550회·DIM 전용 레이어 |
| C5 | 선 종류 구분: 실선/숨은선(파선)/중심선(일점쇄선) | VISIBLE(ANSI) 레이어 관례 |
| C6 | 심볼 블록(밸브·볼트·플랜지·도어류) | INSERT 6,352회 — 심볼 재사용 지배적 |
| C7 | 밸룬-BOM 정합 + 규격 문자열(G1 연동) | BOM 관례 |
| C8 | 용접 기호(조인트별)·주기(notes) 블록 | 제작도 관례 |
| C9 | 레이어 분리(DXF: DIM/CENTER/HIDDEN/HATCH/OUTLINE) | KOTE·PDF_QUOTE 등 실측 |

**측정**: SWRO 벤치 도면을 코퍼스 대표 도면(기계 스키드류)과 항목별 대조 —
전 항목 충족 시 합격. 미충족 항목은 도면 하단에 정직 표기하지 않고 **생성 자체를
보완**한다(체크리스트는 게이트지 면책 문구가 아님).

## 이미 갖춰진 실시 요소 (인벤토리 — 재작업 금지)

- 검증: 간섭 0·부유 0·배관 라우팅 검증·designOk 게이트
- 구조: 질량/CG/지지반력/전도(structuralCheck) + FEA(TET10, 하중 가정 명시)
- 용접: 접촉 자동 검출 → weldTotalMm 물량
- 계산: engineering-core 61종(볼트 체결·좌굴·배관 사이징 STD_DN·피로·베어링 수명…)
- 산출: GA 3면도(중심선)·배치계획도·DXF(레이어)·BOQ+XLSX·Dossier·P&ID 스켈레톤·
  STEP(B-rep)·IFC(비기계)·GD&T(Phase B/C 모듈)

## 실시 수준 갭 — 우선순위 순

### G1. 시판 규격 스냅 (최우선 — 모든 도면·BOM 신뢰의 기반)
현재 배관 Ø60·플랜지 비례값 등 **임의 치수**. 실시도서는 시판 규격이어야 발주 가능:
- 배관: KS D 3507/3562 호칭경(15A~200A) OD·스케줄 두께 표 → pipes.d 를 호칭경으로
  선언, 실 OD/두께 자동. 두께 선정 근거(설계압 → sch 선정식) 계산기 연동
- 플랜지: KS B 1503 클래스(10K/20K…) 별 OD·PCD·볼트 수/호칭 표 → flangedNozzle 이
  규격표 참조(비례식 폐기)
- 형강: 각관/채널/앵글 KS 규격 단면 목록 → 프레임 부재 스냅
- 볼트: M 계열(M8~M24) 호칭 스냅
- 구현: `scripts/drawing-to-3d/std-catalog.json`(규격표 — 출처 명시) + 스냅 함수 +
  "규격 외 치수" 정직 경고

### G2. 부품 단품 제작도
조립 3면도만 존재. 부품별 제작도(가공 치수·판금 전개·공차 기입) 자동 생성:
- 그룹 대표 부품(GA 밸룬 그룹 재사용) → 부품도 시트(3면+치수 전개)
- bent_sheet/판금은 전개도(전개 길이 = 중립면 계산)
- GD&T 모듈 연동(끼워맞춤 공차 기입)

### G3. 용접 상세
총량(weldTotalMm)→ **조인트별 용접 기호**: 접촉 검출 결과에 필릿 각장(판두께 기반
관례 z=0.7t) 산정 → GA/부품도에 KS 용접 기호 표기 + 용접 일람표(WPS 참조 열은 입력)

### G4. P&ID 정식화
스켈레톤 → ISA 5.1 계기 태그(PI/FI/LT…)·라인 넘버링(유체-호칭경-재질)·밸브 리스트·
계기 리스트. 심볼은 코퍼스 실측 심볼 블록 관례 참조

### G5. 제작 사양서 자동화
- 도장: 표면적 산출(부품 표면적 합 — 폐형) → 도장 사양/물량표
- 시험: 수압시험 압력(1.5×설계압 관례 — 근거 명시)·리크 시험 항목
- 검사: 치수 검사 포인트(주요 치수 자동 추출)

### G6. 리프팅·운송 검증
structural CG → 인양 러그 4점 배치 제안+러그 계산(기존 볼트/피로 계산기 연동)·
운송 폭/높이 게이트(도로 제한 3.0m 폭 관례 — 근거 명시)

### G7. BOM 구매 명세화
유형+치수 → **규격 문자열**("PIPE 50A SCH40 KS D 3507", "FLANGE 50A 10K KS B 1503")
— G1 규격표에서 자동 유도. 구매품(임포트 부품)은 모델명 열(입력)

## 실행 순서 (체크리스트 기준 재정렬)

**D-트랙(도면 완성도 — C1~C9 직결)**: D1 완성도 게이트 구현 → D2 시트 체계
(C1: 도곽·표제란·도번·리비전) → D3 단면도+해칭·부분 상세(C2·C3) → D4 선 종류·
치수 체계(C4·C5) → D5 심볼 라이브러리(C6)
**G-트랙(데이터 기반)**: G1 규격 스냅(C7 의 전제) → G3 용접 기호(C8) → G5 사양서 →
G2 부품 제작도 → G4 P&ID → G6 리프팅 → G7 BOM 명세

권장 순서: G1 → D2 → D3 → D4 → G3 → D5 → D1(게이트로 봉인) → G5 → G2 → G4 → G6 → G7.
각 단계 완료 기준: SWRO 벤치 재생성 + 게이트 0/0 + 해당 산출물 검토 가능 상태.

## H-트랙: 결과물 HTML 현장 고도화 (260718 추가)

현장 사용 기준(오프라인·종이·태블릿·검사)으로 HTML 산출물을 승격:

- **H1. 오프라인 자립화(완료 260718)** — GA_3D three.js CDN(unpkg) 의존 제거:
  data:URL 인라인 importmap. 단일 파일 1.4MB, 인터넷 없이 작동
- **H2. 인쇄/PDF 체계** — @page A3 가로 도곽·시트 분할·흑백 인쇄 대응
  (선 종류로 구분 — C5 와 연동, 색 의존 제거)
- **H3. 현장 뷰어 UX** — 터치 핀치줌/팬·밸룬/부품 검색→하이라이트·2D 치수 측정 도구
- **H4. 검사·마크업** — 검사 체크리스트(localStorage 저장)·레드라인 주석(그리기,
  JSON 내보내기/불러오기 — 서버 없이)
- **H5. BOM 인터랙션** — 정렬·필터·체크오프·CSV 내보내기(발주 이관)
- **H6. 문서 일관성** — 공통 표제 헤더(도번·리비전)·시트 간 링크(GA 밸룬↔BOM 행 점프)

우선순위: H1(완) → H2 → H3 → H5 → H4 → H6. D-트랙 시트 체계(D2)와 H2 는 동시 작업.
