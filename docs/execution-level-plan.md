# NexyFab 실시설계 수준 도달 계획 (260718 수립)

목표: **제작사가 이 도서만 받고 제작 착수 가능한 수준**(스키드 장치 기준).
법정 경계(불변): 인허가 제출 도서는 유자격 기술사 날인 영역 — 본 파이프라인은
"제작용 실시도서 + 검토용 계산서(비법정 명시)"까지를 담당한다.

## 이미 갖춰진 실시 요소 (인벤토리 — 재작업 금지)

- 검증: 간섭 0·부유 0·배관 라우팅 검증·designOk 게이트
- 구조: 질량/CG/지지반력/전도(structuralCheck) + FEA(TET10, 하중 가정 명시)
- 용접: 접촉 자동 검출 → weldTotalMm 물량
- 계산: engineering-core 61종(볼트 체결·좌굴·배관 사이징 STD_DN·피로·베어링 수명…)
- 산출: GA 3면도(중심선)·배치계획도·DXF(레이어)·BOQ+XLSX·Dossier·P&ID 스켈레톤·
  STEP(B-rep)·IFC(비기계)·GD&T(Phase B/C 모듈)

## 실시 수준 갭 — 우선순위 순

### G1. 시판 규격 스냅 (최우선 — 모든 도면·BOM 신뢰의 기반)
현재 배관 Ø60·플랜지 비례값 등 **임의 치수**. 실시도서는 시판 규격이어야 발주 가능:
- 배관: KS D 3507/3562 호칭경(15A~200A) OD·스케줄 두께 표 → pipes.d 를 호칭경으로
  선언, 실 OD/두께 자동. 두께 선정 근거(설계압 → sch 선정식) 계산기 연동
- 플랜지: KS B 1503 클래스(10K/20K…) 별 OD·PCD·볼트 수/호칭 표 → flangedNozzle 이
  규격표 참조(비례식 폐기)
- 형강: 각관/채널/앵글 KS 규격 단면 목록 → 프레임 부재 스냅
- 볼트: M 계열(M8~M24) 호칭 스냅
- 구현: `scripts/drawing-to-3d/std-catalog.json`(규격표 — 출처 명시) + 스냅 함수 +
  "규격 외 치수" 정직 경고

### G2. 부품 단품 제작도
조립 3면도만 존재. 부품별 제작도(가공 치수·판금 전개·공차 기입) 자동 생성:
- 그룹 대표 부품(GA 밸룬 그룹 재사용) → 부품도 시트(3면+치수 전개)
- bent_sheet/판금은 전개도(전개 길이 = 중립면 계산)
- GD&T 모듈 연동(끼워맞춤 공차 기입)

### G3. 용접 상세
총량(weldTotalMm)→ **조인트별 용접 기호**: 접촉 검출 결과에 필릿 각장(판두께 기반
관례 z=0.7t) 산정 → GA/부품도에 KS 용접 기호 표기 + 용접 일람표(WPS 참조 열은 입력)

### G4. P&ID 정식화
스켈레톤 → ISA 5.1 계기 태그(PI/FI/LT…)·라인 넘버링(유체-호칭경-재질)·밸브 리스트·
계기 리스트. 심볼은 코퍼스 실측 심볼 블록 관례 참조

### G5. 제작 사양서 자동화
- 도장: 표면적 산출(부품 표면적 합 — 폐형) → 도장 사양/물량표
- 시험: 수압시험 압력(1.5×설계압 관례 — 근거 명시)·리크 시험 항목
- 검사: 치수 검사 포인트(주요 치수 자동 추출)

### G6. 리프팅·운송 검증
structural CG → 인양 러그 4점 배치 제안+러그 계산(기존 볼트/피로 계산기 연동)·
운송 폭/높이 게이트(도로 제한 3.0m 폭 관례 — 근거 명시)

### G7. BOM 구매 명세화
유형+치수 → **규격 문자열**("PIPE 50A SCH40 KS D 3507", "FLANGE 50A 10K KS B 1503")
— G1 규격표에서 자동 유도. 구매품(임포트 부품)은 모델명 열(입력)

## 실행 순서

G1 → G3 → G5 → G2 → G4 → G6 → G7 (G1 이 G3~G7 의 데이터 기반).
각 단계 완료 기준: SWRO 벤치 재생성 + 게이트 0/0 + 해당 산출물 검토 가능 상태.
