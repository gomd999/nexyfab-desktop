# AI 3D 판매·검증 범위 v1

## 목적

AI가 화면에 형상을 표시했다는 사실과 실제 제작 가능한 CAD가 완성됐다는 주장을 분리한다. 판매 중인 기능은 아래 범위와 게이트를 통과한 경우에만 `verified`로 표시한다.

## v1 지원 범위

- 치수가 명시된 판재, 브래킷, 커버, 단순 하우징
- 축·부싱과 단순 회전체
- 파이프·플랜지와 규칙적인 홀 패턴
- 절곡 수와 두께가 명시된 단순 판금
- 부품 수 2~20개의 단순 조립체(메이트와 간극을 별도 검증)

필수 조건은 단위, 기준 치수, 위치 관계, 재료/공정에 필요한 최소 입력이 결정돼 있는 것이다. 누락된 정보는 AI가 임의로 채우지 않고 질문 또는 명시적 가정으로 남긴다.

## 제한 범위

- 단일 사진·스케치에 축척 또는 기준 치수가 없음: `concept_only`
- 유기적 곡면, 인체공학 조형, Class-A 표면: `concept_only`
- 안전 핵심 부품, 압력용기, 의료·항공 인증 부품: 전문가 승인 전 제작 거절
- 복잡한 기구학, 용접 변형, 금형 수축을 포함한 최종 생산 설계: 전문가 검토 필수

## 상태 정의

- `verified`: 해석형 B-Rep, 닫힌 솔리드, 피처 보존, STEP 왕복, DFM 게이트를 모두 통과
- `review_required`: 형상은 있으나 치수·피처·공정·STEP 중 하나가 미확정
- `concept_only`: 메시/자유형 또는 입력 증거가 부족해 제조 정확도를 주장할 수 없음
- `refuse`: 지원 범위 밖이거나 안전상 자동 제작으로 넘겨서는 안 됨

## 코퍼스 운영 규칙

코드 기준선은 `src/lib/ai/manufacturingCorpus.ts`다. 모든 AI 사례는 최소 5회 반복하며 최악값과 평균값을 함께 기록한다. 합성·매뉴얼 파생·내부 도그푸딩·고객 실패를 별도 집계한다.

고객 설계 원문은 기본적으로 저장하지 않는다. `nf_failure_log`의 비식별 서명과 입력 해시를 우선 사용하고, 원문을 보존할 때만 별도 동의 참조를 기록한다. 현재 v1 기준선에는 고객 실패 사례가 0건이며, 따라서 이를 고객 데이터 기반 성능으로 홍보하면 안 된다.

## 다음 확장 조건

각 제품군은 최소 20개 독립 사례, 사례당 5회 반복, 제조 게이트 100% 통과, 치수/피처 정확도 95% 이상, 중대한 허위 `verified` 0건을 만족한 뒤 지원 범위를 넓힌다.
