## 2. P0-① — 라벨은 **표시 계층**에서 고쳤고, 근본은 남겨 뒀다

### 무엇이 문제였나

한국어 문서인데 판정 항목명이 영문 코드 키였다. 실측 결과 **소제목 567개 중 271개(48%)**
가 영문이었다 — 앞 문서가 잰 「판정 라벨 64건」보다 넓다. 판정 노드만이 아니라
`detail`×94 · `needInputs`×48 같은 **구조 컨테이너**가 그대로 소제목이 되고 있었기 때문이다.

### 두 가지를 함께 고쳤다

1. **노드가 이미 가진 이름을 쓴다.** `labelKo` 는 스칼라로 취급돼 소제목엔 `flexure` 가
   뜨고 본문엔 `labelKo=휨` 이 **값처럼** 찍히고 있었다. 이름이 있는데 이름 자리에 안
   들어간 것이다 — 기계가 「영문 0%」였는데도 소제목은 전부 영문이었던 이유가 이것이다.
2. 이름이 없는 키는 **키→한국어 사전**으로 옮긴다.

### ⚠ 사전에 없는 키는 **고지한다**

`rc_frame` 문서 하단:
> ⚠ 이 문서의 다음 항목명은 계산기 내부 키가 그대로 표시됐습니다(한국어 라벨 미등록):
> `U1` · `U2`. 값과 판정은 정상이며, 표기만 보완 대상입니다.

두 건은 계산기가 만든 **하중조합 이름**이라 사전에 넣을 성질이 아니다 — 고지가 맞다.

첫 구현에서 접미 숫자를 떼고 고지해 `U1`·`U2` 가 **`U`** 로 나갔다. 문서에서 찾을 수 없는
키를 고지하면 고지가 조치로 이어지지 않는다 — 실측으로 잡아 원문 그대로 넣게 고쳤다.

### ⚠ 감사 수치는 **줄지 않았다** — 그게 맞다

`domain-audit.mjs` 의 `englishLabels` 는 여전히 49건이다. 감사는 표시 계층을 거치지 않으므로
**계산기가 `labelKo` 를 안 다는 상태**를 잰다. 사전으로 덮은 것을 「해결 0」으로 읽으면
근본이 영영 안 고쳐지므로, 이 수치는 그대로 두고 도구 주석에 그 뜻을 적었다.

## 4. P1-③ — 이 `CHECK` 는 「기준 미달」이 아니라 **「판정 불가」**였다

실측값:
```
{"horizontalM":1.5,"minSlope":"1/100","requiredDropMm":15,"availableDropMm":0,"rises":false,"verdict":"CHECK"}
```
`availableDropMm=0` — 도식 배관 경로는 수평이라 **모델에 낙차가 선언된 적이 없다.**
「구배가 부족하다」가 아니라 「구배를 아직 정하지 않았다」인데 배지만으로는 구별되지 않았다.
이 세션 내내 지킨 구별(해당 없음 ≠ 판정 불가 ≠ 이상 없음)이 여기서 무너져 있었다.

이제 세 사유를 이름으로 나눈다: **상승 구간 존재**(중력배수 불가) / **낙차 미선언**(판정
불가 — 기준 미달이 아니다) / **낙차 부족**(진짜 기준 미달). 승격하려면 배관 경로에 z 낙차를
선언해야 한다 — 형상이 아직 답을 갖고 있지 않다.

## 5. P2-④ — **검토 대상을 정의**하고 나서 검사를 붙였다

`landscape/apartment_complex` 는 51종 중 유일한 실판정 0 조경이었다. 정의 없이 검사를 붙이면

### 검토하는 것 — 형상이 답을 가진 것만
| 항목 | 근거 | 판정 |
|---|---|---|
| 인동간격(가로·세로) | 건축법 시행령 §86③ | **실판정** |
| 건폐율 | 국토계획법 시행령 §84 | 산출만 — 상한은 용도지역이 정한다 |
| 용적률 | 국토계획법 시행령 §85 | 산출만 |
| 조경면적률 | 건축법 §42(조례 위임) | 산출만 |

### 인동간격은 **방향을 지어내지 않고도** 판정할 수 있다

기준이 둘이다: 채광창 직각방향 **0.5H 이상**, 측벽 상호간 **8m 이상**. 어느 면이 채광면인지는
평면이 정하는데 매싱 모델에는 **창이 없다.** 방향을 가정하는 대신 **두 기준을 모두 걸었다**:

- `gap ≥ 0.5H` → 어느 배치로도 적합 (**PASS**)
- `8m ≤ gap < 0.5H` → **배치에 달렸다** (**CHECK** — 무엇이 결론을 가르는지는 밝혀져 있다)
- `gap < 8m` → 어느 배치로도 미달 (**FAIL**)

기본값(15층 43.5m · 25/35m)은 양방향 PASS, 15/20m 은 CHECK, 6/7m 은 FAIL 로 세 갈래가 전부 산다.

### 검토하지 않은 것도 **이름으로** 밝힌다
주차대수(세대수 미선언 — 층수로 추정하면 지어내기) · 일조권 사선(대지경계선 미선언) ·
소방차 진입로(형상에 없음).

### ⚠ 루트에 `labelKo` 를 달았다가 되돌렸다
`labelKo` + `ok:true` 는 렌더러가 **"판정: 적합 ✓"** 배지로 그린다 — 개별 항목이 미달이어도
「검사가 돌았다」가 「단지가 적합하다」로 둔갑한다. `label` 로 바꿔 이름만 나가게 했다.
