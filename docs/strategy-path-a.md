# Path A 대체 전략 — OCCT + planegcs 자체 커널 (260719b)

> **목표**: SolidWorks/Autodesk 를 "일부 전문가만 쓰는 도구"로 만든다.
> **경로**: Path A(오픈소스 커널) 확정 — ADR-013(2026-06-01) 결정 승계. 로열티 0·통제권 100%.
> **전제**: 이 문서는 260719b 코드 실사(테스트 실행·파일 실측) 결과에 기반한다. ADR-016 과

## 1. 실사 결과 — 저장소는 자기 문서보다 훨씬 앞서 있다

`src/lib/sketch` · `src/lib/assembly` · `src/lib/cad` 3개 스택 **77 테스트 파일 / 1,549 테스트 통과**(실행 확인).

| 요소 | 로드맵 표기 | **실제 상태** |
|---|---|---|
| 2D 구속 솔버 | Phase 1 완료 | **완료** — planegcs 1.1.7, 구속 12종, DoF·드래그 솔브, SketchEditor 라우팅됨, 4절링크 인수 테스트 |
| 어셈블리 mate | Phase 3 = 2027 미착수 | **대부분 구현** — mate IR 11종, Lagrangian Newton-LM(1,198줄)+해석적 Jacobian(1,121줄), 그룹 분해, 간섭·서브어셈·모션스터디, API 라우트·UI 배선 |
| 피처 히스토리 | Phase 2 진행 | **구현** — 순서 노드 트리, EditOp 7종(중간 삽입·삭제·**재정렬**·suppress), undo/redo, 브랜치 머지, 영속화 |
| OCCT 커널 | — | **실배포** — `public/occt-worker/opencascade.wasm` 63MB, 실 op 15종(extrude/revolve/boolean/fillet/chamfer/thicken/STEP 입출력/tessellate), UI 배선 완료 |

즉 지난 판단에서 "다년 과제"로 본 항목 중 **1(구속 솔버)·2(mate)·4(히스토리)는 이미 있다.**
남은 것은 사실상 **하나의 기술 리스크와 하나의 배선**이다.

## 2. 진짜 병목 — 세 갈래 스택이 만나지 않는다

| 스택 | 내용 | 커널 경로 | 테스트 |
|---|---|---|---|
| **T1 drawing-to-3d** | 어휘 30종·템플릿 46종·도면집·검도 게이트·AI 판독 | OpenSCAD(메시) + replicad(B-rep) | 190 |
| **T2 Pro CAD IR** | 스케치 솔버·mate 솔버·피처 트리 | **TS 폴리헤드론**(featureMesh) | 1,549 |
| **T3 shape-generator** | 실 OCCT 워커 15 op | OCCT WASM | 다수 |

**피처 트리는 OCCT 로 재생성되지 않는다.** 트리는 TS 메시/SCAD 로만 재생성되고, 진짜 B-rep 은
옆 스택에 있다. 이 이음매가 닫히지 않으면 세 자산이 계속 갈라진 채 각자 늙는다.

> **결론: 다음 투자는 "없는 기능 만들기"가 아니라 "있는 것 잇기"다.** 훨씬 싸고 훨씬 빠르다.

## 3. 남은 기술 리스크는 하나 — 위상 명명 K2.2

현행 2종:

- **생성 이력 명명**(`src/lib/cad/topoNaming.ts`) — `f.side.{i}`·`e.vert.{i}` 를 프로파일 정점
  인덱스에서 파생. **extrude 전용**. 파일 헤더가 스스로 밝힌다: *"Booleans split + merge faces,
  so they need a geometric re-match pass on top (K2.2) — out of scope here."* → 정직한 범위 선언.
  ⚠단 `topoNaming.test.ts` 의 "stable across a rebuild" 테스트는 **항진명제**다(독립 토폴로지 2개를
  만들어 같은 이름이 같은 법선을 주는지 확인 — 이름이 인덱스의 순수 함수이므로 실패할 수 없다).
  구성상 참인 성질이라 무해하지만, **불리언·필렛 후 생존을 검증하지 않는다**.
- **기하 시그니처 매칭**(`shape-generator/features/edgeCorrespondence.ts`) — 실 OCCT 경로에서
  실제로 쓰이는 쪽. `{mid, dir, length}` + bbox 상대 리맵. 파라미터 변경 생존 테스트 있음(진짜).

**미해결**: 불리언·필렛이 면을 쪼개고 합칠 때의 참조 생존. revolve/sweep/loft/pattern 명명.

### 3.1 해법 방침 — 완벽히 맞히지 말고, 틀리면 말하게 한다

Parasolid 급 영속 ID 를 재현하려는 건 지는 싸움이다. 대신 이 저장소의 기존 원칙을 그대로 쓴다:

> 기하 지문 매칭 + **신뢰도 산출** → 애매하면 **"이 참조를 잃었습니다 — 다시 지정해 주세요"** 로
> 명시적 거부. 재생성마다 **참조 생존율을 리포트**.

SolidWorks 는 참조를 잃으면 조용히 다른 모서리를 잡고 모델이 망가진다(사용자는 한참 뒤 발견).
nexyfab 은 A1 라운드트립·C1 3열 대조·D1 역투영과 같은 사상으로 **검출하고 고지**할 수 있다.
**AI 가 형상을 편집하는 제품에서는 이게 더 나은 동작이다** — 조용히 틀린 모델보다 되묻는 게 맞다.
즉 K2.2 는 "Parasolid 의 열등한 복제품"이 아니라 **"검증 가능한 위상 참조"** 라는 다른 물건이 된다.

## 4. 수정된 로드맵

### P1 — 이음매 닫기 (최우선·최대 레버리지)
1. **K2.2 위상 명명 스파이크** — ADR-017. 실패율 실측이 이후 전부를 좌우.
2. **피처 트리 → OCCT 재생성 배선** — `featureTree` replay 가 `occtEngine`/`solidKernel` 호출.
3. **브라우저 워커 K-시리즈 노출** — `variableFillet`·`draft` 가 Node 브리지에만 있음.
4. **`wasmReal.placeholder.test.ts` 실체화** — `it.skip` 4건(STEP 왕복·불리언·필렛)을 실테스트로.
5. **위상 명명 회귀 스위트** — 트리 재생성→불리언 삽입→상류 치수 변경 후 필렛 참조 생존 assert.

### P2 — T1·T2 통합
- drawing-to-3d 어휘/템플릿을 피처 트리 IR 로 표현 가능하게(또는 상호 변환).
- 검도 게이트·A1/B1/C1·도면집을 Pro 트랙 산출물에도 적용.
- 목표: **템플릿으로 시작해 자유 편집으로 이어지는 하나의 파이프라인**. 지금은 두 제품이다.

### P3 — 연동 도면
- HLR 은 가능 판정 완료(260719b, `hlr-spike.mjs`, 3뷰 697ms).
- 치수를 위상 참조에 부착 → K2.2 위에 얹힘. 참조 생존율 리포트 동반.

### P4 — 전문가 구간 회수
- revolve/sweep/loft 명명, gear mate 실배치, Phase 3.6 동역학, 인터롭 왕복 심화.

## 5. 명시적 포기 목록 (전선 확대 방지)

- **Class-A 서피싱** — OCCT 로 불가. 포기.
- **어려운 필렛·블렌드 견고성** — Parasolid 대비 열세. 완전 해결 불가 → **검출·자동 회피(반경 축소
  재시도)·골든 회귀**로 완화하고 한계를 고지.
- **수천 부품 대형 어셈블리** — 브라우저 WASM 천장. 서버 하이브리드로 완화, 한계 인정.
- **SLDPRT/IPT 네이티브** — 불가. STEP/DXF/IGES 경유만.
- **인증 해석** — 스크리닝까지만. 법적 판정 아님(기존 비법정 원칙 유지).

→ 남는 시장: **부품·중형 어셈블리·도면·발주**. 기계 CAD 사용자의 다수가 여기 있다.
서피싱·금형·초대형은 소수 전문가로 남긴다 — **그게 목표 정의와 일치한다.**

## 6. 대체 메커니즘 — 기능이 아니라 중심성

인컴번트는 기능 열세로 죽지 않고 **중심에서 밀려나며** 죽는다(Sketch→Figma, AutoCAD→Revit,
Pro/E→SolidWorks 전부 동일). 그래서 3층으로 간다:

- **확장(Phase 0, 진행 중)** — 비전문가가 발주 가능한 도서를 만든다. 정면 충돌 없이 성장.
  260719b 의 EasyWizard·쉬운 요약·조경 7종/인테리어 9종이 그 씨앗. **Path A(로열티 0)라서 가능한 층**
  — Path B 였으면 시트 로열티 때문에 무료 확장이 막힌다.
- **교두보** — 한 구간에서 **완전**해질 것(부분 우위는 안 팔린다). 후보: 장비·플랜트 프레임/스키드.
- **포위** — ①멀티플레이어 협업(SolidWorks 가 구조적으로 못 하는 것) ②**검도 게이트를 발주 표준으로**
  ③파일 왕복. 발주처가 "검도 통과 붙여 보내세요"라고 말하는 순간 도구가 아니라 **인프라**가 된다.

### 저들이 구조적으로 못 하는 것
- **5분야 통합** — SolidWorks/Revit/Civil3D 는 별개 사업부·가격표. 합치면 자기 매출을 깎는다.
- **AI 에이전트 운전 가능성** — 데스크톱 COM/플러그인 API 는 LLM 이 다룰 물건이 아니다.
  우리는 MCP 26종 + CLI + API 3면이 이미 있다.
- **검증 우선 문화** — 커널이 "신뢰받는" 물건이라 자기 출력을 의심하는 층이 없다.
- **시트 라이선스 포기** — 영업 조직 전체가 거기 걸려 있다.

### Path A 만의 자산
로열티 0(무료 티어 가능) · 통제권 100%(AI API 자유 설계) · **오픈소스 진영이 동맹**
(적이 Dassault/Autodesk 라면 FreeCAD·OCCT 커뮤니티는 우군 — 업스트림 기여가 곧 우리 이익) ·
오픈 표준 서사 일관성.

## 7. 승부 지표

| 층 | 지표 |
|---|---|
| 확장 | 도면집 → **실제 발주·시공**으로 이어진 건수 |
| 교두보 | "이 일은 nexyfab 이 SolidWorks 보다 낫다"가 참인 작업 유형 수 |
| 포위 | 발주처가 검도 리포트를 **요구**한 건수 · 외부 팀 협업 세션 수 |
| 기술 | **위상 참조 생존율**(재생성 후) · OCCT op 실패율 · 골든 회귀 통과율 |

## 8. 정직한 확률

- **Autodesk 전체 몰락** — 비현실적(AutoCAD·Revit·Civil3D·건설 부문 규모).
- **SolidWorks 급 기계 CAD 가 "일부 전문가만 쓰는 것"이 되기** — **가능**. 단 §6 포위층이 성공하고
  교두보를 최소 한 구간 완전히 가져와야 한다.
- **최대 리스크** — 기술이 아니라 **확장층 없이 정면 승부로 가는 것**. 그건 자본력 싸움이고 진다.
- **성공 시 인수 제안이 온다** — 그때 버틸 근거가 "표준을 쥐고 있다"여야 한다.
