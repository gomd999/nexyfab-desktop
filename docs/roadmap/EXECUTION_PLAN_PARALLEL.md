## 0. 병렬 실행 규약 (260719b 실전에서 확립)

### 0.1 파일 소유권 배타 원칙
**한 웨이브 안에서 두 트랙이 같은 파일을 건드리지 않는다.** 위반 시 마지막 쓴 쪽이 이긴다.
각 트랙 지시서에 **"이 파일만 / 절대 금지 파일"** 을 명시한다.

### 0.2 커밋은 오케스트레이터만
에이전트는 **커밋하지 않는다**. 작업 트리에 남기고 보고만 한다. 통합·검토·커밋은 한 곳에서.
이유: 병렬 커밋은 pre-commit(전 프로젝트 tsc)에서 서로의 미완성 코드에 걸려 교착한다.

### 0.3 모든 트랙에 주입할 불변 원칙
> 생성≠검증 · 날조 금지 · 근사는 명시 · 거부는 이유와 함께 · **실행하지 않은 판정은 판정이 아니다**

에이전트가 "구현했다"고 보고해도 **실행 근거(테스트 통과 수치·실측값)가 없으면 미완료**로 처리한다.
260719b 교훈: 이전 감사가 코드 존재만으로 "피처 히스토리 구현됨"을 보고했으나 실행해 보니
하류 재생성이 끊겨 있었다.

### 0.4 웨이브 종료 게이트 (숫자로만 판정)
각 웨이브는 **정량 수용 기준**을 통과해야 다음으로 넘어간다. "된 것 같다"는 통과가 아니다.

### 0.5 병렬화의 한계 (정직)
- **볼륨 문제**(피처 20종 구현, 포맷 5종 익스포트)는 병렬로 거의 선형 단축된다.
- **수렴 문제**(하류 재생성 데이터 모델, 불리언 위상 명명)는 **병렬로 빨라지지 않는다.**
  설계를 한 사람이 확정한 뒤에야 쪼갤 수 있다 → 각 웨이브에 **직렬 선행 구간**을 명시한다.
- 진짜 병목은 **통합·검토**다. 트랙 수를 늘릴수록 오케스트레이터가 병목이 된다 → 웨이브당
  **동시 트랙 상한 6~8**, 그 이상은 웨이브를 쪼갠다.

## 신규 발견 → 로드맵 반영

1. **🔴 브라우저 실커널 STEP 입출력이 죽어 있다** — `public/occt-worker/occt-worker-real.js`
   가 **파일명 11자 이상에서 깨진다**(재현 가능한 정확한 경계). 프로덕션이 쓰는
   `/tmp/out.step`(13)·`cadr_in.step`(12) 둘 다 초과. 커버리지 감사의 "STEP=A등급" 중
   **브라우저 경로는 작동한 적이 없다**. → **신규 트랙 W3-D**(Wave3 로 승격, 회귀 테스트는 고정됨)
2. **FEA 응력 신뢰 범위 축소** — 구멍판 Kt **1.027**(Kirsch 3.0). 복셀 메셔가 집중을 사실상
   감지 못함. `it.fails` 자기소멸 부채 표식으로 고정. → **FEA 는 변위=신뢰, 곡률부 응력
   피크=신뢰 불가**로 취급(W7-A). 이 저장소가 "FEA 된다"고 말할 때의 범위를 좁힌다.
3. **도면 DXF 재분류** — `sheetToDxf` 는 시트 테두리+뷰포트 placeholder 만 방출(투영 엣지·
   치수 엔티티 없음). B등급(배선만)이 아니라 **W4-A 와 같은 실측 배관 의존** → Wave4 로 이동.
4. **`nodeOcctBridge` role→featureId** — 3줄이 아니라 브리지 API 시그니처 변경(planExecutor
   가 `resultId: node.id` 를 갖고 있어 스레딩은 가능). → **W3-A 에 편입**. 현재는 안전 강등
   (명시적 상실)이 걸려 D1 은 지켜짐.
5. **concentric 이 반경을 보존하지 않는다** — 원이 [중심,림] 2점 파라미터화라 중심 이동이
   반경을 바꾼다(r=10→16.008 실측). SolidWorks 는 반경 불변. 근본 해결=(cx,cy,r) 재파라미터화
   = **솔버 모델 변경**. → **신규 트랙 W3-E**(사용자가 즉시 체감하므로 후순위로 미루지 않는다)
6. **DOF 가 초기 만족 시 미계산** — LM 이 `while(err>tol)` 이라 이미 수렴한 스케치는 0회 반복
   → 야코비안 null → DOF 과대보고. **원과 무관한 선재 버그, 전 기하 타입 영향.** → W3-E 동봉
7. **NURBS `fitNurbsThroughPoints` 가 보간하지 않는다** — 이름·docstring 과 달리 입력점을
   제어점으로 복사만 함(실측 편차 9.68/13.68/7.56mm). 현행 Catmull-Rom 이 더 정확하므로
   교체 불가. → **W5 로 이동**(먼저 실제 보간으로 고쳐야 함)
