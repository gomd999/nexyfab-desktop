## 2. 다음 — **P1: 주력 임포트 경로에 커널** ★근거가 가장 확실

### 왜 이것이 1번인가

우리 정체성은 「맞는 것을 수치로」인데, **사용자가 실제로 밟는 경로**
(`/api/nexyfab/drawing/import-step` → `stepToNexyfabAssembly` → `importStepAssembly`)는
전 부품을 **AABB 상자**로 받는다. 리포 자체 회귀에 `최대 58배 과대(ratio 0.017)` 라고 적혀 있다.

정직하게 고지는 한다. 하지만 이제 커널이 실측을 준다 — **정확한 값을 손에 쥐고도 58배
과대를 계속 내보내는 것은 한계가 아니라 모순이다.**

### 설계가 성립한다 — 260801 측정으로 확인

```
트롤리 조립체(7.3MB) → SOLID 205 · SHELL 209 · FACE 8,556
```
`TopExp_Explorer` 로 **솔리드 단위 분해가 된다.** 부품 단위 물량서가 성립한다
(분해가 안 되면 「1부품 64.1kg」이 돼서 못 쓴다 — 그래서 이걸 먼저 쟀다).

### ★확인 완료 — 커널이 **정확 부피·표면적·무게중심**을 준다 (260802 실측)

`measureShapeVolumeProperties` 는 `GProp_GProps` 래퍼를 돌려주고, 값은 `_wrapped.Mass()`
· `.CentreOfMass()` 로 꺼낸다. 정확부피를 아는 형상(⌀100×200 원기둥)으로 대조:

```
부피     1,570,796.327  vs 폐형 1,570,796.327  → 오차  0.000000%
표면적      78,539.816  vs 폐형    78,539.816  → 오차 -0.000000%
무게중심 (0, 0, 100)    — 기대와 일치
```

**메시가 필요 없다.** 이 사실이 설계를 바꾼다:

| 종전 가정 | 실측 후 |
|---|---|
| 커널 = 삼각 메시 → 곡면 부피 **−0.26~−0.62% 과소** | **0.000000%** — 편향이 없다 |
| 7.3MB 파일 메시 **17초** | 메시 불필요 — 질량·물량은 즉시 |
| 메시는 부피 산출의 **수단** | 메시는 **표시 전용**으로 격하 |

⚠ 따라서 `stepKernelImport` 의 「곡면 부피 최대 0.7% 과소」 고지는 **메시를 쓸 때만**
유효하다. 정확 부피 경로로 바꾸면 그 문장을 **함께 고쳐야 한다** — 안 고치면 과소 고지가
남아 「있지도 않은 오차를 있다고」 적는 것이 된다(반대 방향의 과고지).

### 덤으로 풀리는 것 — `composite` 표면적

지금 복합 부품 표면적은 **미산출**이고 BOQ 가 이름으로 고지한다(접촉면을 알 수 없어서).
커널은 표면적도 정확히 준다 — **도장·도금 물량이 처음으로 산출된다.**

### 단계

1. ~~호출 규약 확인~~ **완료(260802)** — 위 표 참조
2. 솔리드 분해 → 부품 배열 (`TopExp_Explorer`, 자식 프로세스 러너 확장).
   각 솔리드마다 **정확 부피·표면적·무게중심**을 함께 낸다(메시는 표시용으로만)
3. `stepToNexyfabAssembly` 가 AABB 대신 커널 부품을 쓰도록 — **AABB 경로는 폴백으로 남긴다**
   (커널 실패 시 종전 동작 + 고지)
4. 회귀: 코퍼스 파일 1개의 부품 수·총질량이 AABB 대비 얼마나 줄어드는지 **수치로 고정**
5. `stepKernelImport` 를 정확 부피 경로로 전환하고 **메시 편향 고지를 함께 정정**
6. `composite` 표면적 산출(도장·도금 물량) — 현재 미산출 고지를 실제 값으로 대체

### ⚠ 성능 예산

부품이 수백 개면 자식 프로세스 1회로 전부 처리해야 한다(프로세스당 WASM 초기화 ~1초).
코퍼스 실측 최대 17,269 부품 — **상한과 대표화 규약**이 필요하다. 상한 초과는
**거부하고 이유를 적는다**(잘라 받으면 형상이 거짓).

## 7. 작업 규약 (이 세션에서 반복 확인된 것)

### H2 — 그 다음 (커널이 새로 열어 준 길)

**★ 메시에서 파라메트릭으로 되돌아가기 (feature recognition)**

지금 커널 임포트의 근본 한계는 「부피·경계는 실측인데 **치수를 고쳐 재생성할 수 없다**」는
것이다. 그런데 커널은 **면을 종류별로 준다**(실측: FACE 8,556 · `CYLINDRICAL`·`PLANE`·
`CONICAL`·`TOROIDAL` 구분 가능). 그러면 단계적으로 되돌릴 수 있다:

| 단계 | 무엇 | 왜 가능한가 |
|---|---|---|
| ① **홀 인식** | 원통면 쌍 → `holes[{x,y,d}]` | 축·반경이 면에 선언돼 있다 |
| ② **모따기·라운드 인식** | `CONICAL`/`TOROIDAL` 면 → `chamferMm`/`filletMm` | 260801 에 **어휘를 이미 만들었다** |
| ③ **판재 인식** | 평행 평면 2장 + 측면 → `extrude_profile` | 분류기가 이미 하는 일 |

⚠ 이건 **분류기를 다시 짜는 게 아니다.** 지금 분류기는 STEP **원문**을 읽는데, 여기서는
커널이 **정규화한 면**을 읽는다 — 원문 방언·sense 플래그·곡선 종류를 커널이 흡수한 뒤라
훨씬 견고하다. 260801 에 우리가 손으로 고친 것들(sense 플래그·B-스플라인·타원)을
커널이 이미 처리한 상태로 준다.

⚠ **하지만 이건 큰 작업이고, 하기 전에 「필요한가」를 물어야 한다.** 사용자가 임포트한
형상을 실제로 **수정**하는지, 아니면 **물량·검토만** 뽑는지 — §6 측정으로 먼저 확인한다.
수정하지 않는다면 실측 메시로 충분하고, 이 트랙은 통째로 불필요하다.

**그 밖의 H2**

- **정확 무게중심을 구조 검토에 연결** — 전도·지지 판정이 지금은 선언 형상 기반이다.
  임포트 형상은 커널 CG 가 정확하므로 그걸 쓰면 판정이 실물에 붙는다.
- **표면적 미산출 어휘 정리** — `boq.mjs` 에 `return null` 이 4곳이다. 커널이 있는 지금
  몇 개는 산출 가능하고, **불가능한 것은 이유를 유지**한다(과고지 금지).
- **AI 경로 회귀** — §6-2 측정 결과에 따라. 지금은 결정론 경로만 회귀가 있다.

### H3 — 구조적 부채 (지금 아프지 않지만 계속 비용을 낸다)

| 부채 | 증상 | 관측 |
|---|---|---|

## 9. 순서를 정하는 규칙

기능 목록이 아니라 **판단 기준**을 적는다. 다음에 무엇을 할지는 이 규칙으로 정한다.

1. **우리가 파는 것과 실제가 어긋난 것이 최우선.** 기능 부족보다 모순이 더 나쁘다.
   (예: 정확도를 파는데 주력 경로가 58배 과대)
2. **재보지 않은 것은 개선하지 않는다.** 측정이 먼저다 — 이 세션에서 측정 하나가
   우선순위를 통째로 뒤집었다(「OCCT 경로가 필요하다」 → **이미 리포 안에 있었다**).
3. **과고지를 만드는 개선은 개선이 아니다.** 기능을 넣으면 고지도 함께 옮긴다.
4. **큰 작업 전에 「필요한가」를 묻는다.** H2 의 feature recognition 이 그 예다 —
   사용자가 임포트 형상을 수정하지 않으면 통째로 불필요하다.
5. **같은 부류의 사고가 두 번 나면 구조를 고친다.** 한 번은 우회, 두 번은 신호.

## 10. 하지 않기로 한 것 (근거와 함께)

기록해 두지 않으면 반복해서 다시 논의하게 된다.

| 항목 | 왜 안 하나 |
|---|---|
| 원뿔·원환 **임포트** 지원 | 코퍼스 셸 383개 중 순수 원뿔 **0** · 원환 2 · 혼재 381. 지어도 2건 늘고 「지원한다」는 과고지만 남는다 |
| 모따기 「형상 손실 %」 고지 수신 | 커널이 실형상을 주므로 **불필요해졌다**(260801 P0.5 폐기) |
| 컨셉 이미지 품질 경쟁 | 이미지 모델이 하는 일이라 곧 상품화된다 |
| ISO 286 `p·s·u·c` 를 기억으로 채우기 | 기본편차가 IT 등급에 걸린 규칙이라 한 점에서 역추정하면 과적합 |

## 11. 이 계획을 폐기해야 할 신호

계획이 틀렸다는 것을 **미리 정해 두면** 늦게 깨닫지 않는다.

- §6-1 측정에서 **주력 경로가 이미 잘 되고 있으면** → P1 의 전제가 무너진다(58배는 최악값일 수 있다)
- §6-2 에서 **AI 경로 성공률이 매우 낮으면** → 임포트보다 그쪽이 1번이다
- 사용자가 임포트 형상을 **수정하지 않는다면** → H2 feature recognition 트랙 전체 폐기
- 커널 도입 후 **패키지 지연이 실사용을 막으면** → 잡 큐(H3)가 H1 으로 올라온다
