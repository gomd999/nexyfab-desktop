# NexyFab 글로벌 서비스 약관 기준선

- 작성일: 2026-08-09
- 약관 버전: `GTS-1.0-2026-08-09`
- 서비스 범위: AI 기반 복잡 제품 생성, 수동 브라우저 CAD, 정밀 CAD, 전문가 검토, 파일 처리, 협업 및 제조 연계
- 적용 원칙: 설계물별 법무 심사를 요구하지 않고, 서비스 운영 약관과 설계물의 기술 검증을 분리한다.

## 결론

기존 약관은 제조 파트너 매칭과 고정 수수료 규정에 치우쳐 있어 글로벌 AI CAD SaaS 약관으로는 부족했다. 웹 약관을 다음 기준으로 교체했다.

1. 입력 자료와 결과물의 권리
2. 비공개 CAD·도면의 제한적 처리권한
3. 공용 AI 학습 기본 비활성화와 별도 옵트인
4. AI 생성, 자동 검증, 전문가 검토, 릴리스 상태의 구분
5. 전문가 기술 검토와 법무·특허·인허가 검토의 분리
6. 제조·시공·안전·규제 용도의 검증 책임
7. 지식재산권 및 불법 자료 신고·제한·반론 절차
8. 지역별 강행 소비자권리와 개인정보 권리 보존
9. 제3자 CAD 제품·상표·파일 형식의 호환성 표시 원칙
10. 제재·수출통제 및 고위험 용도 제한

약관의 실행 원본은 `src/content/globalTerms.ts`이며, 실제 페이지는 `/{lang}/terms-of-use/`이다.

## 기존 Closed Beta 보호

- 기존 ID와 비밀번호를 변경하지 않는다.
- 기존 고객 파일과 저작물을 이전·삭제·재분류하지 않는다.
- 약관 버전 변경만으로 과거 비공개 자료를 AI 학습에 사용하지 않는다.
- 데이터 마이그레이션이 필요하면 별도 고지와 데이터 정책을 적용한다.
- 기존 전문가 검토 결과는 파일·리비전·해시·검토 범위에 결합하며, 약관 개정 때문에 임의로 무효화하지 않는다.

## 서비스상 권리 구조

| 대상 | 기본 권리 | NexyFab 권한 |
|---|---|---|
| 사용자가 업로드한 CAD·도면·문서 | 사용자에게 유지 | 서비스 제공·보안·백업·협업에 필요한 제한적 이용권 |
| 사용자 전용 AI/CAD 결과물 | 관련 법률과 제3자 권리를 전제로 사용자에게 귀속 | 서비스 자체 요소와 기존 자료는 제외 |
| 범용 템플릿·표준 매핑·UI·알고리즘 | NexyFab 또는 라이선스 제공자 | 사용자에게 소유권 이전 없음 |
| 비공개 고객 자료의 AI 학습 | 기본 비활성화 | 별도 명시적 옵트인 또는 서면 기업계약이 있는 경우만 가능 |
| 비식별·집계 원격측정 | 개인정보 처리방침과 법률 범위 | 서비스 보안·품질 개선에 이용 가능 |

## 검증 상태와 책임 경계

| 표시 상태 | 의미 | 실제 적용 전 요구사항 |
|---|---|---|
| AI 생성 | AI가 결과를 생성했으나 목적별 검증이 완료되지 않음 | 치수·재료·공차·하중·용도 검증 |
| 검증 대기 | 필수 자동 또는 사람 검토가 남아 있음 | 현실 적용 금지 또는 보류 |
| 자동 검증 완료 | 표시된 자동 검사 범위를 통과함 | 검사 외 항목과 실제 사용조건 검증 |
| 전문가 검토 필요 | 실패 영향이나 불확실성 때문에 사람 검토가 필요함 | 자격·경험을 갖춘 전문가 검토 |
| 전문가 검토 완료 | 특정 버전·해시·범위에 대한 기술 검토가 기록됨 | 변경 시 재검증, 법정 인허가는 별도 |
| 릴리스 완료 | 정의된 기술 릴리스 게이트가 충족됨 | 구매자·제조자·시공자의 최종 적용 확인 |

전문가 검토는 기술 검토다. 저작권, 특허 실시자유, 영업비밀 업로드 권한, 인허가와 같은 법률 판단을 대신하지 않는다. 반대로 법률 고지 한 줄도 보안, 정확도, 데이터 격리 또는 기술 릴리스 검증을 대신하지 않는다.

## 글로벌 적용 방식

- 글로벌 기준본은 영문이다.
- 대한민국 소재 사용자에게는 대한민국 강행법이 요구하는 범위에서 한글본이 우선한다.
- 일본어·중국어·스페인어·아랍어 경로는 현재 정확성을 위해 영문 약관과 현지어 안내문을 표시한다.
- 해당 언어권에서 유료 B2C 영업을 본격 시작하기 전에는 현지 법률용어를 반영한 완전 번역본을 게시하고 버전 일치를 검증한다.
- 준거법은 대한민국법으로 두되 소비자가 상거소 국가에서 가지는 강행 권리와 이용 가능한 법원을 박탈하지 않는다.
- 복잡한 국제 중재·집단소송 포기 조항은 넣지 않았다. 국가별 유효성 차이가 크고 초기 글로벌 서비스에 불필요한 분쟁을 만들 수 있기 때문이다.

## 약관 외 운영상 필요한 작업

아래 항목은 약관 문구만으로 완료되지 않는다.

1. 신규 동의기록에 약관 버전, 시각, 사용자, IP, User-Agent를 보존하는 별도 불변 로그
2. 기존 사용자는 권리를 줄이는 중대한 변경이 있을 때만 재동의 대상으로 분리
3. `nexyfab@nexysys.com`으로 들어오는 권리침해 신고의 담당자, 처리기한, 제한·복구·이의제기 기록
4. 미국 DMCA 면책을 실제로 사용할 경우 미국 저작권청 지정대리인 등록 및 공개
5. EU 이용자가 업로드 자료를 제3자와 공유하는 호스팅·플랫폼 기능을 사용할 경우 DSA 신고·조치 및 이의제기 운영절차 확인
6. EU·EEA 및 영국 개인정보의 국외 이전 수단, 처리자 목록, 보존기간을 개인정보 처리방침과 실제 인프라에 일치
7. 결제 도입 시 판매국별 자동갱신, 청약철회, 디지털 서비스 적합성, 세금 및 환불 화면 구현
8. 국가별 유료 출시 전 사업자 정보, 고객지원 연락처, 번역본, 소비자 특약 확인

## 공식 기준을 반영한 이유

- EU Digital Services Act는 중개·호스팅 서비스 약관에 콘텐츠 제한과 조치 기준을 명확하고 접근 가능한 형태로 설명하도록 하고, 호스팅 서비스에는 전자적 신고·조치 절차를 요구한다.
- 미국에서 호스팅 서비스가 DMCA 면책을 주장하려면 단순 이메일 고지를 넘어 저작권청 지정대리인 등록 등 법정 절차가 필요하다.
- EU 개인정보 고지는 처리자, 목적, 법적 근거, 보존기간, 수령자, 국외 이전 및 정보주체 권리를 설명해야 한다.
- EU 원격계약과 디지털 서비스에는 청약철회·적합성 등 강행 소비자권리가 적용될 수 있으므로 일률적인 환불 불가·무책임 문구를 두지 않았다.
- EU AI Act의 특정 투명성 의무와 대한민국 AI 관련 표시 의무를 고려해, AI 사용과 검증 상태를 약관뿐 아니라 제품 화면과 내보낸 증거에도 표시하는 구조를 유지한다.

## 출시 판단

현재 약관은 Closed Beta와 기술 검증에 사용할 수 있는 글로벌 기준선이다. 다만 이것만으로 모든 국가에 즉시 유료 판매가 가능한 것은 아니다. 유료 국가를 추가할 때마다 위 운영 작업과 개인정보·결제 특약을 확인해야 한다. 이 확인은 고객 설계마다 수행하는 법무 심사가 아니라, 판매 국가와 서비스 기능이 바뀔 때 수행하는 플랫폼 단위 점검이다.
