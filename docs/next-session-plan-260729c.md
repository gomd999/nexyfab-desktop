## 2. 이번 실측이 새로 찾은 것

### ⚠ A. 기계 6종에서 **전도가 문서에 한 글자도 안 나온다** (P0)

```
tower_crane: mechCheck.checks = { staticTipover, seismicTipover }   ← 계산은 된다
             안전검토.html    = "검토 불가: 카운터웨이트…"           ← 전도 없음
             verdict.unavailable = ["입력 필요: 카운터웨이트…"]      ← 전도 없음
```

`domainSafetyReportHtml` 의 `r.ok === false` 분기가 **checks 를 통째로 버리고** "검토 불가"
카드만 그린다. P1-5 에서 배선한 정적 전도가 **정작 그것이 유일한 판정인 6종에서** 사라진다.

이 세션에서 반복해 잡은 「조기 반환이 고지를 삼킨다」의 **네 번째** 사례다(공간 고지 ·
`lateralUnavailable` · `basis` 조건 · 그리고 이번). 같은 형태가 계속 나온다는 것은
**패턴을 고쳐야 한다**는 뜻이다 — 개별 자리를 막는 것으로는 끝나지 않는다.

### ⚠ B. `cafe_room` 에 위생기구·배관이 하나도 없다 (P1)

부품 39개짜리 카페인데 `fixtures 0 · pipes 0` 이라 배수·통기 검사가 「대상 없음」으로 빠진다.
`two_room` 도 같다. **검사 결함이 아니라 템플릿 데이터 갭**이다 — 실제 카페는 싱크·화장실이
있고, 그것이 인테리어 검사의 핵심 입력이다. 어휘도 검사도 이미 있는데 **쓸 데이터가 없다.**

### ⚠ C. 새 어휘·검사를 쓰는 출하 템플릿이 없다 (P2)

- `slab_with_openings` 를 쓰는 **건축 템플릿 0개** (관통 검사가 늘 「관통 없음」)
- 벽 관통 대조도 **합성 테스트에서만** 재현된다
- `tapered_girder` 는 260729b 에 템플릿을 만들어 해소했다 — 같은 처방이 필요하다

어휘를 만들고 검증까지 해도 **출하 경로가 없으면 실사용에서 무엇이 깨지는지 알 수 없다.**

## 3. 다음에 할 일

### P0 — 판정이 소비자에 도달하지 않는 자리

1. **`ok:false` 결과의 checks 를 버리지 않는다.** "검토 불가" 카드는 유지하되 계산된
   checks 를 함께 그린다. ⚠ 개별 자리를 막지 말고 **렌더 진입점 하나에서** 처리한다 —
   같은 형태가 네 번째다.
2. **verdict 의 `unavailable` 에도 실판정 결과를 함께 올린다.** 지금은 needInputs 만 올라가
   쉬운요약에서 "전도는 봤다"는 사실이 사라진다.

### P1 — 데이터 갭 (검사는 있는데 쓸 입력이 없다)

3. **`cafe_room`·`two_room` 에 위생기구·배관 선언.** 카페는 싱크·화장실·급배수가 실무
   구성이다. 넣으면 배수·통기·수용인원 검사가 실제로 돈다.
4. **기계 깊이 2.9 — 여전히 최저.** 간섭(`buildAssembly.interferences`)이 기계 판정에
   들어가는지 **아직 확인하지 않았다**(전도와 같은 자리일 가능성). 확인 후 판단.
5. **조경 — 실판정이 2종뿐.** 나머지 6종은 목재가 없어 정당하지만, 조경 고유 검토
   (식재 기반·배수 구배·포장 두께)는 계산기가 있는데 템플릿이 입력을 안 준다.
   `landscape-check` 의 `planting_base`·`slope_bishop` 이 그 자리다.

### P2 — 출하 경로

6. **`slab_with_openings` 를 쓰는 건축 템플릿** — 계단실·승강로 관통이 있는 다층 건물.
   `commercial_massing` 에 계단실 개구를 넣는 것이 자연스럽다(슬래브 5장 중 2~4층).
   그러면 관통 검사가 **실사용에서** 돈다.
7. **벽 관통이 있는 템플릿** — `duct_run` 의 덕트가 벽을 지나가게 하거나 별도 템플릿.

### 확인만 필요한 것

8. **토목 3종이 `domainSafety` null** — 검증.html 로 가는 것이 맞다. 다만 패키지에서
   두 문서(안전검토·검증)가 **어떻게 함께 읽히는지** 확인한 적이 없다. 한쪽만 보는
   소비자가 다른 쪽 판정을 놓치지 않는지.
