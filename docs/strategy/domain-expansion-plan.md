## 1. 핵심 아키텍처 — 3층 분리 (RAG≠검증)

RAG는 지식 검색이지 계산이 아니다. "RAG로 검증"은 권위 있게 들리는 틀린 검증을 낳는다. 대신:

| 층 | 역할 | 구현 |
|---|---|---|
| ① 지식층 (RAG) | 기준·논문 검색, **조항 인용**("KDS 41 §x.x에 의해"), 설계 가이드 | R2 코퍼스 + 임베딩(NexyFlow RAG 076 스택 재사용) + NexyFab AI 추상화 |
| ② 계산층 (결정론) | 분야별 **부재검토 계산기** — 코드로 구현, 입력→수치→판정 | intent 모듈 패턴 (TS + 게이트 + throw) |
| ③ 검증층 (골든벤치) | 교과서·기준 예제 풀이와 수치 대조 — FEA 스위트 1016테스트 패턴 | vitest 골든테스트. RAG는 벤치 예제 **발굴**에만 사용 |

모든 산출물 라벨: **"구조 검토 참고자료(비법정)"** — 법정 계산서는 기술사 날인 영역. 기술사에겐 도구로 판매.

## 2. 코퍼스 — 저작권-안전분만 크롤링 (2026-07-11 확장: 다국 기준)

**핵심 법리: 공식·계산방법은 저작권 보호 대상이 아니다(아이디어-표현 이분법) — 보호되는 건 원문 텍스트.** 따라서 검증(계산기 구현)은 전세계 기준 전부 가능하고, RAG 원문 코퍼스만 라이선스로 제한된다.

| 소스 | RAG 원문 수록 | 계산기 구현 | 비고 |
|---|---|---|---|
| KDS/KCS (한국) | ✅ kcsc 무료공개 | ✅ | 공공누리 유형 확인 후 수집 — **1순위** |
| 미 연방 간행물 (FHWA·USACE·NIST·FEMA·OSHA) | ✅ **퍼블릭 도메인** | ✅ | 최대 무료 영문 코퍼스 |
| Eurocode(EN)·AISC 360·ACI 318 | ❌ 유료 저작물 | ✅ 공식 구현 + **조항 번호 참조만** | 원문 미수록, 인용 표기는 사실정보라 가능 |
| 오픈액세스 논문(DOAJ·arXiv)·만료 저작물·OCW | ✅ | 골든벤치 원천 | |
| 특허 | FTO/기술조사 분류만 | ❌ 검증 근거 아님 | |

- **다국 기준 = 계산기 파라미터**: `standard: 'KDS'|'AISC'|'EC3'|...` — 역학 공통, 계수·안전율만 분기. **기준별 골든테스트**로 각각 검증 → 한국+국제 검증 동시 충족.
- 저장: R2 `/knowledge/{kds|usgov|papers|examples}/` + **문서별 라이선스 메타데이터 필수**(D1: 출처 URL·라이선스 유형·수집일) — provenance 없는 문서는 코퍼스 반입 금지. 임베딩 Vectorize.
- 크롤러: robots.txt 준수, 원문 유료 사이트 우회 수집 금지.

## 4. 왜 이 조각인가 (전면 커버 반대 근거 요약)

- NexyFab 유일 축 = 검토에서 끝나지 않고 **3D·도면·공장 견적·제작까지 연결** (마이다스가 못 하는 것)

## 7. 분야별 구체화 — "단일 CAD AI"가 아니라 공통 코어 × 분야 모듈 (2026-07-11)

### 7.0 플랫폼 매트릭스

**공통 코어 4개** — 분야가 늘어도 코어는 하나:

| 코어 | 내용 | 현재 상태 |
|---|---|---|
| K (지식) | RAG 코퍼스+임베딩+조항 인용 | Wave 1 완료(미연방 8문서), KDS manual 잔여 |
| C (계산) | 결정론 계산기 프레임: intent 게이트, `standard:` 파라미터(KDS/AISC/EC…) | 패턴 확립(FEA 스위트), 분야 모듈 미착수 |
| V (검증) | 골든벤치 하네스(vitest, 기준별 예제 대조) | FEA 1016테스트 패턴 재사용 |
| F (제작연결) | 3D 모델러·HLR 도면·견적·공장 27만 매칭 — **NexyFab만의 축** | 라이브 |

**분야 모듈 = 얇은 레이어**: 계산기 세트 + 코퍼스 태그 + 골든벤치 + 검토서 템플릿. 분야 추가는 코어 재작성이 아니라 모듈 4종 세트 추가.

**분야 개설 4게이트 (빈 약속 칸 금지의 구체화)** — 아래 4개를 못 채우면 사이트에 칸을 만들지 않는다:
1. 코퍼스: 해당 분야 라이선스-클린 문서 ≥3종 인덱싱
2. 계산기: 결정론 모듈 ≥1종 (intent 게이트 통과)
3. 골든벤치: 기준/교과서 예제 대조 ≥10케이스 PASS — **역산 재현 포함** (아래 리버스 엔지니어링 4트랙)
4. 버티컬 랜딩: 실물 데모 콘텐츠 1페이지 (실제 산출물만)

**리버스 엔지니어링 검증 4트랙 (2026-07-11 채택 — 해설서 부재 대체 전략)**: 해설서·예제집 없이도 "공표된 수치를 우리 엔진이 재현"하면 동등한 검증력:
1. **공표 예제/내력표 역산 재현**: 코퍼스 내 풀이 예제(SBDH·EM 부록)·제조사 카탈로그 적재하중표·공표 단면내력표를 우리 계산기로 역산해 수치 일치 확인. ✅ 1호 완료: SBDH Vol.14 볼트이음 예제 — 공표값 55.42 kips/bolt·892.5 kips를 AASHTO 파라미터 세트(`standards/aashto-lrfd.json`)로 0.3% 이내 재현 (골든테스트 REVERSE-ENG 2케이스)
2. **교차표준 정합**: 동일 역학·계수만 분기이므로 표준 간 내력비 = 계수비 — 분석적으로 검증 가능. ✅ KDS/AISC 볼트 내력비=Fnv비 테스트
3. **독립 솔버 교차검증**: FEA 스위트(1016테스트 검증済)와 simple_beam 등 폐형식 계산기의 동일 문제 대조 — Wave 2
4. **방법 구현 후 재현**: EM 1110-2-2502 웨지법(SMF) 구현 → Appendix N Example 1 공표값(ΣV=56.41k/ft 등) 재현 — P2 옹벽의 실질 게이트

### 7.1 기계·장비·판금 (앵커 — 현재 본업)

- **대상**: 부품/시제품 발주자, 장비·스키드 제작사 (위시빌더 등)
- **역할**: 다른 분야의 기준점. 모든 신규 분야 산출물이 여기의 견적·공장매칭으로 합류
- **추가 계산기(후순위)**: 리프팅 러그·아이볼트 검토, 용접 사이즈 근사, 스키드 베이스 프레임 처짐 — ASME BTH-1/AWS는 조항 참조만(유료 저작물)
- **코퍼스**: 기존 + OSHA/USACE 리프팅 관련 PD 문서(Wave 2 후보)

### 7.2 P1 가설·랙·경량철골 (첫 신규 모듈 — ULD 랙에서 이미 근접)

- **대상**: 랙 제조사(AK엔지니어링), 물류설비사, 비계/동바리 시공사, 경량철골 제작소
- **계산기** (입력→판정, 전부 결정론):
  - 압축재 좌굴: 단면+KL/r → 허용압축력 (KDS 14 31 / AISC 360-E 파라미터 분기)
  - 휨재: 단면+지간+하중 → 휨·전단·처짐 판정 (KDS 14 31 / AISC 360-F)
  - 랙 프레임: 기둥 유효좌굴+빔커넥터 → 단 적재하중표
  - 볼트 접합: 전단/지압/인장 (코퍼스 근거: SBDH Vol.14 ✅)
  - 베이스플레이트+앵커: 압축·인발
  - 비계 작업하중: KDS 21 60 00(대기) / OSHA 1926 Subpart L(근거문서 ✅ OSHA 3150)
- **코퍼스 실측**: SBDH Vol.4/13/14 + OSHA 3150 ✅ / KDS 14 31·21 60 manual 대기
- **골든벤치**: AISC 매뉴얼 예제(수치는 사실정보), KDS 해설 예제, ULD 랙 실계산 대조
- **제작연결**: 랙 3D 파라메트릭 모델 → 부재검토 → HLR 도면 → 공장 견적 (풀 루프 데모 = 버티컬 랜딩 콘텐츠)
- **안 하는 것**: 지진 시 랙 거동해석(RMI/FEM 영역), 시스템비계 전체 FE

### 7.3 P2 토목 소구조물

- **대상**: 소규모 토목설계사무소, 시공사 기술부, 개발행위 인허가 대행
- **계산기**:
  - 옹벽 안정 3종: 전도(합력 편심 e≤B/6·FS), 활동(FS≥1.5), 지지력 — **코퍼스 근거 EM 1110-2-2502·GEC11 ✅ 이미 확보**
  - 보강토옹벽 외적안정: KDS 11 80 10(대기) + GEC11 ✅
  - 쏘일네일 예비검토: GEC7 ✅
  - 암거 단면검토(1셀 박스), 배수 용량(합리식)
- **골든벤치**: EM 2502 부록 설계예제, GEC11 Chapter 예제 — **코퍼스에서 직접 발굴 가능(①층의 정당한 용도)**
- **제작연결**: 옹벽 전개도/철근 물량 산출 → 도면 → (프리캐스트라면) 공장매칭
- **안 하는 것**: 교량 FE·시공단계·케이블·사면 전체 안정해석(지반 FE)

### 7.4 P3 건축 부재검토

- **대상**: 건축구조 기술사사무소(**날인 전 검증 도구**로 판매 — 경쟁이 아니라 보조), 소규모 건축설계사무소
- **계산기**:
  - 단순보/연속보: 휨·전단·처짐·균열 (KDS 14 20 RC / 14 31 강구조)
  - 기둥: P-M 상관도 단면검토
  - 접합부: 볼트·용접 단순접합 (SBDH Vol.14 ✅ + KDS 41 대기)
  - 슬래브 근사해법(계수법), 기초 독립기초 지지력·펀칭
- **코퍼스**: KDS 41·14 manual 대기가 핵심 — **이 모듈은 KDS 없이 개설 불가**(4게이트 §7.0-1 미충족)

- **안 하는 것**: 건물 전체 해석, 내진성능설계, 기초 침하 FE

### 7.5 P4 건축설계 (도면·배치)

- **대상**: §7.4와 동일 + 인테리어/소규모 증축
- **범위**: HLR 기반 2D 도면 자동생성(P0 엔진 재사용), 간단 배치도(이격거리·주차 대수 등 **산술 규칙만** — 법규 판단은 조항 인용+참고자료 라벨), DXF 왕복
- **안 하는 것**: BIM/IFC 실시설계, 인허가 도서 자동작성(법정 서류)

### 7.6 공통 산출물 규격 (모든 분야 동일)

- **검토서**: 입력 echo → 적용 기준·조항 인용(K층) → 계산 과정 수치(C층) → 판정 → "구조 검토 참고자료(비법정)" 라벨 + 골든벤치 버전 표기
- **분야 = UI 태그일 뿐**: 계산기 레지스트리 하나에 `domain:` 태그, 코퍼스도 `tags:`(이미 sources.json에 구현) — 사이트 IA(§5)가 이 태그를 그대로 노출
