# 설계 분야별 IA — 사이드바 재구성 (아이디어→설계→검증(상시)→제조)

> 2026-07-12 확정. NexyFab "디자인" 좌측 IA를 **숙련도/기능 혼재** → **분야(도메인) 주축**으로 재편.
> 근거: 도메인 확장 계획 §7 "공통 코어 × 분야 모듈" 매트릭스 + 사용자 요구("설계는 모든 분야로 나뉘어야, 검증은 항상").

## 1. 문제 — 현재 사이드바의 축 혼재
현행 "디자인" 항목: 자유형 Studio / 전문가형 CAD(=숙련도 축) + 종이·레이저컷 / 완제품 평가(=기능/출력 축). 서로 다른 두 축이 평면에 섞여 있고, 여기에 분야(토목/건축…)를 더하면 N×M 폭발.

## 2. 결정 — 3축 정리
| 축 | 위치 |
|---|---|
| **분야(도메인)** | ★ 사이드바 **주 네비게이션** (사용자가 "무엇을 설계하나"로 생각) |
| **숙련도** (자유형 AI ↔ 전문가형 CAD) | 각 분야 **안의 토글** (진입 방식만 다름) |
| **검증** | 별도 메뉴 아님 — **모든 설계 흐름의 상시 게이트** (§4) |
| **출력/제조** (STL·STEP·도면·HTML·견적·공장매칭) | 모든 흐름의 **말단 공통** |

## 3. 사이드바 구조 (제안)
```
디자인
  홈
  ── 설계 (분야별) ──
  🔧 기계·장비·판금        파트/어셈블리/판금 (본업)
  🏗 가설·랙·경량철골      프레임 + 부재검토(좌굴·휨·볼트)
  🌉 토목 소구조물          옹벽·암거 + 안정검토(전도·활동·지지력)
  🏢 건축 부재              보·기둥·기초 + KDS 14 20/41
  🌳 조경 구조·배수         데크·옹벽 + 우수배수(합리식)
  ── 자산 ──
  내 프로젝트 / 공유된 항목 / 부품 라이브러리
```
- **"완제품 평가" 메뉴 제거** → 검증을 각 설계 화면 상시 패널로 흡수. 필요 시 "설계 검토 대시보드"(지난 설계 검증상태 모아보기)로 성격 전환.
- 종이·레이저컷은 출력 형식이므로 분야 무관 — 각 설계 결과의 **내보내기 옵션**으로 이동.

## 4. 분야 모듈 계약 (공통 코어 × 얇은 분야 레이어)
분야 진입 시 아래만 분야별로 갈리고, 나머지는 공통 코어 재사용:
| 요소 | 분야별 | 공통 코어 |
|---|---|---|
| 설계 생성 | 프리셋·단위·재료 기본값 | **compose_3d(범용 자유조합)·전문가 CAD 모델러** |
| **검증(상시)** | 분야 계산기(옹벽/보/좌굴/배수) + KDS/AISC 인용 | **manifold 실렌더·게이트·간섭검사** (compose API가 이미 매번 수행) |
| 출력 | (동일) | STL·STEP·2D도안(HLR)·HTML뷰어 |
| 제조 연결 | (동일) | 견적·공장 매칭(F코어) |

**핵심**: 설계 생성(compose_3d)은 분야 무관. 분야가 결정하는 건 **무엇을 검증하고 무엇을 인용하는가**. 그래서 분야 진입 = "범용 설계 + 그 분야 검증·인용·제조연결".

## 5. "검증은 항상" — 상시 게이트 (사용자 핵심 요구)
```
아이디어 → [설계] → 상시 검증(자동, 별도 클릭 없이):
              ① manifold 실렌더 (compose API가 이미 수행)
              ② 분야 계산기 (옹벽 안정/보 휨/좌굴 …) — 해당 시
              ③ KDS/AISC 조항 인용 + "비법정 참고" 라벨
           → [제조 연결] 견적·공장매칭
```
검증 실패 = 형상 미생성/경고(잘못된 설계 진행 차단). 이것이 마이다스·솔리드웍스와 다른 NexyFab의 상시-검증 해자.

## 6. 정직한 게이트 (§7.0 — 빈 분야 금지)
분야 노출 조건: 라이선스-클린 코퍼스 ≥3 + 결정론 계산기 ≥1 + 골든벤치 + 실물 데모.
현재(2026-07-12) 전 분야 **검증 계산기 LIVE**(engineering-core): 기계/판금·가설랙·토목옹벽·건축부재·조경배수. 단 **설계-특화 프리셋은 미비**(compose_3d 범용) → 분야 진입은 "범용 설계 + 분야 검증"으로 정직 노출, 프리셋(탱크·옹벽 단면 등)은 채우며 "베타" 뗌.

## 7. 구현 현황·순서
- ✅ 서버: `/api/nexyfab/drawing/compose` (AI조합→게이트→교정→**manifold 검증**) 실증
- ⬜ 서버: `/api/nexyfab/drawing/export-step`·`/render-html` (같은 webpackIgnore 패턴)
- ⬜ 서버: 분야 검증 연결 — 설계 결과 치수를 engineering-core 계산기(nexyfab-eng-api)에 전달
- ⬜ 프론트: 분야별 사이드바 + 설계 화면(텍스트 입력→compose API→브라우저 openscadWorker 렌더→상시 검증 패널→제조연결)
- ⬜ "완제품 평가" → "설계 검토 대시보드" 성격 전환
