사용 가이드

첫 설계부터 리뷰까지 — NexyFab 전체 흐름을 한눈에

7개 카드 중 궁금한 것을 펼쳐보세요. 카드 안에 단계별 안내가 있고, 관련 페이지로 바로 가는 버튼도 있습니다.

  1. 상단 메뉴에서 "3D 모델러" 클릭 → shape generator 열림
  2. 왼쪽 패널에서 시작 도형 (큐브/원기둥/구 등) 선택
  3. 파라미터 슬라이더로 치수 조절. 실시간으로 3D 뷰 갱신
  4. 오른쪽 위 메뉴 → "STL 내보내기" 또는 "STEP 내보내기"로 다운로드
3D 모델러 열기 →
