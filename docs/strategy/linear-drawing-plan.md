# 선형·도서 심화 계획 — 공차·중첩·정합 무결 스펙 (2026-07-17)

목표: "IP·R·등고 입력 → 평면+종단+횡단+토공+구조물 검토 **도면집** 자동"을,
이 세션에서 실제 겪은 결함 클래스(회전 AABB 과탐·접합부 겹침·초단 조그·표기 반올림
자기모순·REV 드리프트)가 **설계 단계에서 불가능**하도록 게이트와 함께 구현한다.

원칙(불변): 내부 mm double 무반올림 · 표기 시점에만 반올림 · 단일 소스(alignment)에서만
파생 · 생성≠검증 분리(산출물에서 숫자 회수 대조) · 미확보 데이터=정직 생략(날조 금지).

## 0. 공통 무결성 규약 (전 항목 선행 — 이것부터 코드로)

### 0.1 공차 사다리 (geometry-tolerance.mjs 신설, 전 모듈 단일 소스)
| 상수 | 값 | 용도 |
|---|---|---|
| `EPS` | 1e-6 mm | 수치 동일성(부동소수 비교) |
| `TOL_CONTACT` | 2 mm | 접촉/체결 vs 간섭 분류(기존 CONTACT_MM 승격) |
| `TOL_TRIM_RESIDUAL` | 0.5 mm | 트림 후 잔여 겹침 허용(간섭 0 판정 여유) |
| `SAG_TOL` | 25 mm (파라미터) | 원호→현 분할 새그 공차 |
| `MIN_SEG` | max(2·stemT, 1000) mm | 분절 후 최소 세그먼트(초단 조각 금지) |
| `MIN_TANGENT` | 2·baseW mm | 곡선 사이 최소 직선 여유 |

표기 반올림 규약: STA 라벨=m 반올림(허용오차 500mm+EPS) · 길이=fmtLen 사다리
(1/6/501mm — 기존) · 각도=0.1° · 표고=0.01m. **표기값끼리 연산 금지** — 합계·차는
원값으로 계산 후 반올림, 표의 자기정합(BC+L=EC 등)은 최대잔여법 or 원값 재반올림.

### 0.2 회전 풋프린트 정밀 판정 (중첩 오류의 근본 해결)
현재 회전 부품 간섭은 AABB(보수 과탐) → "트림을 크게 잡아 회피"라는 임시방편이
접합부 갭을 낳는다. **2D OBB-SAT**(`obb2d.mjs`: 회전 직사각형 분리축 판정,
겹침 깊이 반환)을 신설해:
- buildAssembly 간섭 검사: 회전 부품 쌍은 AABB 1차 → OBB 2차 정밀(z 겹침은 구간 비교).
- 선형 접합 트림을 "baseW 일괄"에서 **정확 마이터 트림** `m = (baseW/2)·tan(|Δ|/2)`
  + TOL_TRIM_RESIDUAL 로 축소 — 갭 최소화·겹침 0 동시 달성.
- 게이트: 선형 어셈블리는 OBB 간섭 0 필수(테스트 고정).
검증: SAT 자체를 폐형 앵커로 테스트(직교/45°/동일 중심/접촉 정확 0 케이스).

### 0.3 chainage 단일 함수
`alignment-geom.mjs` 신설: 요소열(직선|원호) 모델과 `chainAt(s) → {p, dir, elemIdx}`,
`chainLength()`, `intersectWithPolyline()`, `intersectWithSegment()`. 평면·종단·시트·
구조물 배치·물량·DXF **전부 이 모듈만** 사용(재구현 금지 — 현재 package/dxf에 있는
chainPoint 를 이관·단일화).

### 0.4 시각 골든 (Wave 4-1 선행)
Playwright 스크린샷 골든 6종(직선 run·L형 선형·1.3km 곡선·rc_frame·studio·deck+site),
픽셀 diff ≤ 0.5%. 함정: file:// 는 pathToFileURL(공백·한글), repo 루트에서 실행.
갱신 절차: 의도 변경 시 `--update-golden` 플래그로만. 이후 전 작업의 시각 안전망.

## 1-1. 원곡선(단곡선 R)

입력: `curves: [{ip: i, R}]` (IP별 선택). 완화곡선=명시 보류.

폐형: Δ=정규화(brg₂−brg₁, (−180°,180°]) · TL=R·tan(|Δ|/2) · L=R·|Δ|(rad) ·
BC=STA(IP)−TL · EC=BC+L. 총연장 재계산(직선 단축+호 연장).

**사전 게이트(중첩·불능 원천 차단)**:
1. |Δ| ≤ 90° (초과=선형 재설계 요구, 정직 거부)
2. 인접 곡선 간 `TL_i + TL_{i+1} + MIN_TANGENT ≤ IP간 거리` — 곡선 겹침 불가
3. R ≥ baseW·2 (벽폭 대비 최소 반경 — 안쪽 자기교차 방지: 내측 옵셋 반경 R−baseW/2 > 0 보장)

3D 형상: 분할각 `θc = 2·acos(1 − SAG_TOL/R)`, 현 수 = ceil(|Δ|/θc). 현 박스는
마이터 트림 `m=(baseW/2)·tan(θc/2)` — OBB 간섭 0을 수학으로 보장, 바깥 틈 ≤ 2·SAG_TOL
(도식 밴드·평면은 **진짜 원호**(SVG path A / DXF ARC)로 그리므로 시각 갭 없음, 3D만
현 근사임을 노트). **물량=호장 기준**(현 합 아님 — 차이율 명시).

곡선표 시트: IP·Δ·R·TL·L·BC/EC STA. 자기정합 게이트: |표기BC+표기L−표기EC| ≤ 표기단위.

테스트: Δ=0인 IP 자동 제거 · R 미지정 IP 혼합 · TL 초과 거부 · OBB 간섭 0 ·
chainAt(BC)/chainAt(EC) 접선 연속(방위 차 < 0.01°) · 총연장 = Σ요소장(EPS).

## 1-2. 선형 위 구조물 STA 배치

입력: `structures: [{sta, type: 'culvert'|'catch_basin'|'expansion_joint', params, offset?}]`.

배치: chainAt(sta)의 좌표·접선방위로 회전 배치. **벽 분절 규칙**(교차 구조물=암거):
벽 세그먼트를 [sta−w/2−clr, sta+w/2+clr] 구간에서 갭 — 분절 후 양쪽 조각이 MIN_SEG
미달이면 **정직 거부**("STA 조정 필요", 자동 이동 금지). 갭=개구 명세(슬리브 사상)로
산출(폭·여유·양측 마구리 처리 후속 명시).

게이트: ① 0 ≤ sta ≤ total ② 구조물 간 최소 이격(OBB 간섭 0 — 두 구조물이 같은 STA
근방이면 거부) ③ 곡선 구간(BC~EC) 배치 시 "접선방위 배치·직선 구간 권장" 주석.

체인 연동: culvert→`box_culvert_frame`(기존 계산기) 자동 실행, 미지원 type은
"검증 미지원" 명시. **구조물 일람표**(STA·종류·규격·검토 판정) 시트.

정합 3자: 일람표 STA ↔ 평면 마커 ↔ 종단 마커 — 생성 후 HTML 회수 대조(게이트).

## 1-3. 등고→지반선 결정론 파생

알고리즘: 각 contour 폴리라인 × 선형 요소(선분-선분 폐형, 선분-원호=원·선분 교차
폐형, 판별식 |D|<EPS=접점 1개) → (sta, elevM) 점열 → sta 정렬 → profileGround.

**정직 게이트**: ① 교차점 < 2 → 미생성("등고가 선형을 충분히 덮지 않음")
② 동일 sta(±500mm)에 상이 표고 → **데이터 모순 오류 보고**(평균 내지 않음 — 날조 금지)
③ 보간=교차점 사이 선형만, **외삽 금지** — 교차 범위 밖 구간은 지반선 없음(점선 종단+주석)
④ `source:'contours-derived'` 표기, 종단 주석 "등고 입력에서 보간 파생(측량 성과 아님)".

테스트: 직선·호 각각 교차 폐형 앵커 · 접점 케이스 · 모순 데이터 거부 · 범위 밖 무외삽.

## 1-4. 토공량·유토곡선

전제: 1-3 지반선 존재 구간만. 단면: A(sta)=(지반고−시공기면고)×기면폭 + 사면 사다리꼴
(경사 1:n 입력) — 폐형. **불균등 간격 그대로 평균단면법** V=Σ(Aᵢ+Aᵢ₊₁)/2·Δs
(재샘플 금지 — 재샘플=보간 오차 이중화). 절/성토 부호 분리.

mass_haul(기존 계산기) 연계 → 유토곡선 시트(누적·균형점 — 계산기 산출 그대로).

게이트: Σ구간V = 누적곡선 끝값(EPS) · 평균단면법=근사 명시(프리즘/등고법 후속) ·
기면폭·사면경사=입력 원칙(기본값 날조 금지 — 미입력 시 토공 생략).

## 2-1. 시트 페이지 분리 + 표제란

- 시트=독립 `<section class="sheet-page">`, `@media print{page-break-after:always}`.
- **sheetRegistry**(생성기 한 곳): 도번 `NX-{CIV|ARC|LND|INT}-{GA|PL|PF|XS|CT|DL}-{SEQ}`
  순차 부여 — 산재 부여 금지. 표제란 값(도번·축척·REV·시트 i/n)은 basis 객체에서만 주입.
- 시트 윈도=반개구간 [sᵢ, sᵢ₊₁) (마지막만 폐) — 측점 틱 이중 계상 0, match line 은
  양 시트 동일 STA 표기(관례상 의도된 중복 — 물량과 무관 명시).
- 게이트: 윈도 합집합 = [0,total] 틈·겹침 0(구간 합산 검사) · 도번 유일성.

## 2-2. 도면 목록표 + 2-3. 정합 확장

목록표=sheetRegistry에서 직접 생성 후, **역방향 게이트**: 산출 HTML들을 재파싱해
도번·REV·축척 회수 대조(생성≠검증).

packageConsistencyCheck 추가 체크: ①평면 최대 STA ↔ alignment.totalMm(tol 500mm)
②종단 x축 끝 ↔ 동일 ③BOQ 연장 ↔ 동일 ④곡선표 max EC ↔ 총연장 ⑤일람표 STA ⊂ [0,total]
⑥목록표 행수 = 실제 시트 수 ⑦전 시트 REV 동일.

## 2-4. 일반주기 시트

사용된 계산기들의 `refs`(KDS 조항)를 실행 이력에서 수집 → 적용 기준 목록(중복 제거·
조항 정렬). 근거 없는 일반문구 금지 — refs 에 있는 것만.
