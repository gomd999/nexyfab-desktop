## 4. 이번에 **실제로 틀렸다가 잡은 것** 6건

> 이게 이 문서에서 제일 값어치 있는 부분이다. 다음에 또 이렇게 틀린다.

### ① 이식은 베끼기가 아니다 — 원본의 버그도 따라온다
PBAS `jointTypeForEnd` 는 구속이 하나일 때 `joints[0]` 와 `joints[len-1]` 이 **같은 것을
가리켜** 캔틸레버를 「양단 고정」으로 만든다. 그대로 옮겼고 **K 가 2.0 대신 0.5 →
좌굴 하중 16배 과대**. 가장 위험한 부재가 가장 안전해 보였다.
→ **손계산 대조 회귀를 안 붙였으면 못 잡았다. 이식분에도 우리 회귀를 새로 써라.**

### ② Gram 행렬을 거치면 정밀도가 절반이다
σ(J) 를 λ(JᵀJ) 의 √ 로 얻으면 조건수가 제곱되고 **참값 0 인 특이값이 `√eps·σmax ≈
1.5e-8·σmax`** 로 뜬다. 공차를 `eps·σmax`(≈2e-16)로 잡아 노이즈를 랭크로 세었고
**슬라이더-크랭크 자유도가 1 대신 0** 이었다.
→ 「이론상 0 이니 아주 작을 것」이 아니라 **쓰는 알고리즘이 0 을 얼마나 0 으로 만들 수
있는지**가 공차다. 랭크 상한 `min(행,열)` 도 명시적으로 걸어라(rank 32 > rows 30 이 났다).

### ③ 한 사례가 맞았다고 맞은 게 아니다
위 ②에서 **4절 링크는 우연히 맞았다**(랭크 오차가 자유도에 안 드러나는 배치였다).
슬라이더-크랭크를 같이 안 넣었으면 「검증 통과」로 넘어갔다.
→ **답을 아는 사례 여러 개**로 재라. 지금은 4절·슬라이더크랭크·평행사변형·6축팔 4종이다.

### ④ 죽은 경보를 만들지 마라
`illConditioned` 임계를 1e10 으로 잡았는데, 공차가 `√eps·σmax` 라서 **조건수 상한이
구조적으로 ≈3e6** 이다 — **영원히 안 걸린다.** 없는 경보보다 나쁘다(「검사했는데 정상」으로
읽힌다). → 임계값을 쓸 때 **도달 가능한지 먼저 재라.** 지금은 공차 대비 상대치고,
실제로 걸리는 자세(토글 4절, 조건수 ≈4e4)를 회귀로 못박았다.

### ⑤ 다른 개념에 같은 목표치를 걸지 마라
베어링 **수명비**에 **응력 안전율** 2.0 을 그대로 걸어, 수명 2083h / 요구 2000h 인
**정상 설계가 불합격**으로 나왔다. 응력 SF 2 는 「허용의 절반만 쓴다」, 수명비 2 는
「요구의 두 배를 산다」다. L10 은 이미 신뢰도 90%를 품고 있어 이중으로 깎인다.
→ `targetLifeRatio`(기본 1)로 분리했다. **이름이 둘 다 「안전율」이어도 같은 게 아니다.**

### ⑥ 새 키를 붙이기 전에 이름 충돌을 봐라
선언 접촉을 `contacts` 로 실으려다 **기하로 판정한 `contacts`(zero-thickness 맞닿음)를

**「판정한 것」과 「선언한 것」은 다른 데이터다.**

### (보너스) 접지가 없으면 두 방법이 다른 것을 센다
Kutzbach 의 `n−1` 은 **암묵 접지**인데 야코비안만 접지를 안 해서 **전체 강체 6자유도가

### (보너스2) 필터가 판정을 삼킨다

## 5. 지켜 온 정직성 규약 (신규 모듈 공통)

- **미검토를 통과로 세지 않는다.** 하중·제원이 없으면 `pass:false` 가 아니라
  `status:'pending'`·`pass:null` 이고 **무엇이 필요한지** 적는다. 없는 항목의 안전율을
  ∞ 로 두고 최솟값을 내면 **제원을 안 적을수록 통과율이 오른다** — 정확히 거꾸로다.
  부분검토는 `conditional` 이고 **안 본 파괴모드를 이름으로** 적는다.
- **항복점 없는 재료에 fy 를 지어내지 않는다.** 회주철·콘크리트·유리·FRP 는
  `ELASTIC[m].fy = null` + `noYield` 사유. 채우면 **가장 위험한 재료가 가장 안전해 보인다.**
- **선별을 판정으로 팔지 않는다.** 좌굴 결과마다 `precheck:true` +
  「법정 검토는 `column_buckling`(AISC 360 §E3)」 + 가정 목록(표 대표값·유도 K·국부 미검토).
- **약축으로 잰다.** 주축 최소 2차모멘트로 회전반경을 낸다. 강축으로 재면 λ 가 작아져
  좌굴을 통째로 놓친다.
- **`designOk` 에 넣지 않는다.** designOk 는 「조립이 성립하나」(간섭·부유·배관),
  체결부·좌굴은 「하중을 버티나」다. 섞으면 제원 미기재로 조립 판정이 떨어지거나
  체결부 불합격이 조립 성공에 묻힌다.
- **면제 규칙은 한 곳에만.** 억지 끼워맞춤은 `pairExempt` 안에서만 판단하고,
  `contacts[{kind:'interference-fit'}]` 는 `pressFitWith` 로 **정규화**될 뿐이다
  (문법은 둘, 규칙은 하나). **크기 상한**도 건다 — 선언만으로 무제한 면제하면
  「끼워맞춤이라 적었으니 통과」로 총체적 배치 오류를 덮는다.
- **안 잰 것과 0 은 다르다.** 선언이 없으면 결과 키 자체가 안 붙는다.
