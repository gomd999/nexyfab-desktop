## Phase 1 — 직접 편집 (Direct Editing) ★진행
SolidWorks/Fusion 전환 사용자가 첫날 찾는 기능. 면 출처 복구로 차단 해제됨.
1. **Delete Face**: 선택 면 제거 + 이웃 면 힐링 (OCCT RemoveFaces). 임포트 STEP 디피처링 용도.
2. **Move/Offset Face**: 선택 면 법선방향 오프셋/이동 (OCCT offset/thickening 또는 prism 재구성).
3. **Replace Face**: 후순위 (사용 빈도 낮음).
- 피처 트리에 directEdit 노드로 기록 (히스토리 유지), 메시 폴백 시 downgradeNotice.
- 수용 기준: 임포트한 STEP의 보스 제거 + 벽면 1mm 오프셋이 B-rep으로 성립.

## Phase 2 — 고급 메이트 + 기구 시뮬레이션
1. Limit (거리/각도 범위), Width(중앙정렬), Path, **Gear(비율)**, Cam.
2. 기구 드래그: 메이트 충족 상태에서 부품 끌기(스케치 드래그-솔브와 동일 철학, matesSolver 재사용).
- 수용 기준: 4절 링크 + 기어쌍이 드래그로 구동.

## Phase 3 — 도면 BOM + 벌룬
어셈블리 도면 → BOM 테이블(부품명/수량/재질) + 자동 벌룬. 제조 연계(견적/RFQ)와 직결되는 차별화 지점.
- 기존 자산: holeTable/리비전 패턴, bomParts 데이터, DrawingPageContent PDF 파이프라인.
- 수용 기준: 5부품 어셈블리 도면 1장에 BOM+벌룬 → PDF.

## Phase 4 — 커널 강건성 코퍼스 (상시 트랙)
- 실패한 필렛/셸/불리언 케이스를 코퍼스로 축적 (burnin-step-corpus 패턴 재사용).
- 실패 시 자동 회피(반경 축소 제안, 엣지 분할) + 명확한 에러 메시지.

## 검증 트랙 — 레퍼런스 부품 20개 (각 Phase와 병행)
