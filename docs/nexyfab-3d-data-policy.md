이 문서는 NexyFab 3D 모델링 도구가 처리하는 **사용자 생성 3D 데이터**, **AI 프롬프트**,
**제조 견적 견본 데이터** 의 흐름과 보존·삭제 규칙을 명문화합니다. 기존 약관 / 개인정보처리방침 /
환불정책의 우선순위는 변하지 않으며, 본 문서는 그 위에서 3D 도구 특유의 사항을 보충합니다.

## 1. 사용자 생성 3D 콘텐츠의 소유권 (Ownership)

| 항목 | 정책 |
|---|---|
| **소유권자** | 사용자 (저작권·디자인권 등 모든 IP) |
| **NexyFab의 권리** | 서비스 제공·표시·백업·캐싱에 필요한 비독점적·로열티 프리 라이선스 (계정 유지 기간 동안만) |
| **3자 공유** | 사용자가 명시적으로 공유 링크/협업 초대를 활성화한 경우에 한함 |
| **상업적 사용** | 사용자가 자유롭게 사용 가능. NexyFab은 사용자 모델을 마케팅 자료·학습 데이터로 사용하지 않음 |

**파일 형식 범위**: `.nfab` 프로젝트, STEP/IGES/STL/GLB/OBJ/DXF/PDF 출력물, 자동 도면, 견적 패키지.

## 2. AI 기능 사용 시 데이터 흐름

NexyFab 3D는 NL→SCAD intent 추출 등에 외부 LLM API를 사용합니다.

### 2.1 데이터 경유 경로

| 단계 | 데이터 | 보관처 | 보존 기간 |
|---|---|---|---|
| 1. 사용자 NL 프롬프트 입력 | 텍스트 prompt | 브라우저 → NexyFab API | 즉시 처리, 미보존 |
| 2. AI 추론 호출 | prompt + system prompt | DeepSeek / Anthropic / OpenAI (사용자 지역에 따라 자동 라우팅) | 각 제공자 정책에 따름 (보통 30일 이내 삭제) |
| 3. JSON intent 캐싱 | shapeId + params | NexyFab Postgres | 90일 이내 자동 삭제 (재현성·디버그용) |
| 4. SCAD/STL 결과 | 출력물 | 사용자 프로젝트에만 저장 | 사용자 삭제까지 |

### 2.2 AI 학습 데이터 사용 옵트아웃

- **기본값: 옵트아웃** — 사용자 prompt와 결과는 외부 LLM의 학습 데이터로 사용되지 않습니다.
- 각 제공자 (DeepSeek/Anthropic/OpenAI) API 호출 시 학습 차단 헤더를 항상 전송합니다.
- 사용자가 명시적으로 "improve NexyFab AI" 토글을 켠 경우에 한해 익명화 후 평가셋 보강에 사용 가능.

### 2.3 민감 정보 차단

NexyFab 클라이언트 텔레메트리는 다음을 자동으로 마스킹합니다:
- JWT, Bearer 토큰, 쿠키, API 키
- 이메일 주소
- Windows / Unix 사용자 경로 (`C:\Users\foo` → `C:\Users\[USER]`)

Sentry / 내부 텔레메트리 모두 동일 정책. 외부 LLM에 보내는 prompt는 사용자 입력 그대로 전달되므로
**민감 정보를 prompt에 포함하지 마세요** (UI 안내 필요).

## 3. 제조 견적 (RFQ) 데이터

| 항목 | 정책 |
|---|---|
| 견적 요청 시 공유 데이터 | 모델 형상, 재료, 표면 조도, 공차, 수량, 납기 |
| 공유 대상 | 사용자가 선택한 공급사만 |
| NexyFab의 위치 | **중개자 (passthrough)** — RFQ 내용 자체는 보관하지 않음. 메타데이터(공급사, 일시, 견적가)는 사용자 대시보드용으로 보관 |
| 공급사 측 정책 | 각 공급사 자체 약관에 따름 (NexyFab은 공급사 약관 게시를 요구함) |
| 신뢰도 표시 | 견적가 옆에 confidence band (R2-기반) 표시 — 사용자가 제조 가능성을 판단 가능 |

**수출 통제**: 군용·이중용도 부품 설계는 사용자 책임으로 EAR / KFTA 등 수출 통제 법령을 준수해야
합니다. NexyFab은 EAR99 미만으로 분류되는 일반 산업용 부품에 대한 일반 도구입니다.

## 4. 보존 기간 및 삭제

| 데이터 종류 | 보존 기간 | 삭제 트리거 |
|---|---|---|
| 활성 프로젝트 (.nfab) | 무제한 (구독 유지 시) | 사용자 명시적 삭제 또는 계정 폐쇄 |
| 자동 저장 스냅샷 | 5개 슬롯 (가장 오래된 자동 폐기) | 새 슬롯 추가 시 |
| 클라우드 동기화 버전 히스토리 | 최근 30개 또는 최근 90일 (Pro), 최근 10개 또는 30일 (Free) | 한도 초과 시 가장 오래된 항목 |
| 데모 모드 세션 (`nf_sessions`) | 30일 cron auto-prune | `/api/cron/demo-session-prune` 일일 실행 |
| 결제 / 구독 기록 | 7년 (세법 준수) | 영구 (개인 식별 정보는 6개월 후 익명화) |
| AI 호출 metadata | 90일 | cron auto-prune |
| 견적 메타데이터 | 사용자 대시보드 보존, 사용자 삭제 시 즉시 | 사용자 삭제 |

**계정 폐쇄 시**: 모든 사용자 콘텐츠는 30일 보관 (잘못된 폐쇄 복구용) 후 영구 삭제.
백업에서의 완전 삭제는 90일 이내 보장.

## 5. 환불 정책의 3D 도구 특이사항

기본 환불 정책 (구독 결제일로부터 7일 이내 미사용 시 전액 환불) 위에서:

- **유료 AI 토큰**: 일별 cap을 사용한 만큼 차감, 미사용 분에 대해 7일 이내 환불 가능.
- **STEP export 사용 후 발견된 호환성 문제** (예: 일부 viewer에서 cylinder 재-import 실패):
  명시된 호환 viewer(`canExportStepCleanly` 게이트가 통과한 케이스) 외 환불 불가.
  비호환 viewer 사용은 사용자 책임.
- **공급사 견적의 가격·납기 변동**: NexyFab은 견적 추정치를 신뢰도 표시와 함께 제공하며, 실제
  공급사 견적과의 차이에 대해 책임지지 않습니다. 환불 사유가 되지 않습니다.

## 6. 데이터 이전 (Data Portability)

사용자는 언제든지 다음 형식으로 자신의 데이터를 추출할 수 있습니다:

- 단일 프로젝트: `.nfab` 다운로드 (자체 포맷, 사양 공개)
- 전체 계정: 설정 → "내 데이터 내보내기" → ZIP (모든 .nfab + 메타 + 결제 이력)
- 응답 시간 목표: 30일 이내 (GDPR Art. 15 준수)
