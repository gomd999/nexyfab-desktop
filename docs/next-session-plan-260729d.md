## 3. 다음에 할 일

### P0 — 없음

이번 실측에서 「판정이 사라지거나 뒤집히는」 자리를 **찾지 못했다.**
⚠ 이것은 「없다」가 아니라 **「이번 측정 방법으로는 안 보인다」**는 뜻이다.
다음 세션은 **측정 방법을 바꿔서** 보는 것이 맞다(아래 §4).

### P1 — 남은 실판정 0 (4종)

1. **`building/steel_canopy`** — 지붕 골조형이라 하중경로 적용범위 밖이다.
   `loadPathCheck` 는 정직하게 거부하지만, **캐노피에 맞는 검토가 없다**:
   풍 상향력(uplift)이 지배하는데 `wind_static` 은 있고 연결이 없다.
   `steel_canopy` 는 **풍하중 검토 경로를 붙일 수 있는 유일한 후보**다.
2. **조경 3종**(`apartment_complex`·`fence_run`·`pavilion`) — 목재도 제원 메타도 없다.
   `fence_run`(부품 109)·`pavilion`(12)은 제원을 선언하면 자기정합이 가능하다.
   `apartment_complex`(11)는 단지 배치라 검토 대상 자체가 모호하다 — **먼저 정의가 필요**하다.

### P1 — 인테리어 입력 대기 25건

전 분야 입력 대기 35건 중 **25건이 인테리어**다. 무엇을 요구하는지 아직 훑지 않았다.
채울 수 있는 것(형상에서 파생 가능)과 정말 사용자 입력인 것을 **나눈 적이 없다** —
`cafe_room` 처럼 **템플릿이 선언만 하면 되는 것**이 섞여 있을 수 있다.

### P2 — 교량 미판정 고지 3건

`Lb_chord_out_mm`(면외 좌굴) · `Lb_rib_mm`(아치 리브) · `towerSteel`(RC 주탑).
전부 정직한 요구지만, **템플릿이 그 값을 선언할 수 있는지** 검토한 적이 없다.
횡브레이싱이 형상에 있으면 면외 좌굴장은 파생 가능하다.

### P2 — 기계 미판정 고지 16건

전 분야 19건 중 16건이 기계다. 대부분 지진 전도(`seismicG` 미선언)와 좌굴 요구다.
`seismicG` 는 **지역이 정하는 값**이라 지어낼 수 없다 — 다만 **패키지 파라미터로 받는
경로가 있는지**(verifyParams) 확인한 적이 없다. 있으면 사용자가 줄 수 있다.

## 4. 다음 세션의 측정 방법 제안

이번 세션에 측정으로 세 번 틀릴 뻔했고, 전부 **표시 계층을 통해 셌기 때문**이다.
다음은 방법을 바꾸는 것이 낫다:

1. **검사 트리를 직접 순회**한다(HTML 을 거치지 않음). `runDomainSafetyCheck` 를 export
   하거나 감사용 진입점을 만든다 — 표시가 바뀌어도 측정이 흔들리지 않는다.
2. **판정 항목을 이름으로 나열**해 세션 간 diff 를 뜬다. 수치만 비교하면 「무엇이 늘고
   무엇이 사라졌는지」를 놓친다.
3. **쉬운요약(소비자 문서)에 도달한 것**을 따로 센다. 이 세션의 결함 대부분이
   「계산은 됐는데 소비자에 안 닿음」이었는데, 그건 안전검토.html 만 봐서는 안 보인다.
