## 3. 고친 것

### 임포트
- **곡선**: B-스플라인 de Boor · `ELLIPSE` · `FACE_BOUND` 단일 · **`ADVANCED_FACE` sense 플래그**
  (마지막 하나가 가장 컸다 — 판재 캡이 둘 다 +Z 로 나와 두께를 못 정했다)
- **커널 폴백**: OCCT `importSTEP`. **자식 프로세스**로 — 인라인은 힙 3.7GB 에서 죽는다(2회 재현)
- **주력 경로**: 솔리드 단위 분해 + **정확 물성**(부피·표면적·무게중심). AABB 는 폴백으로 유지
- **동시성 상한**: `KERNEL_MAX_CONCURRENT=2`(실측 445MB 근거) · 슬롯 누수 회귀

### 판정·검토
- **ISO 286 산식** + 핀·보어 끼워맞춤 (양쪽 선언 시에만 판정)
- **공차 누적**(worst-case·RSS) — 체인은 **선언받는다**, 방향 미선언은 거부
- **솔리드 원뿔·원환** 어휘 — 부피·겉넓이 정확식
- **composite 빼기 절단** — 관통 커터가 허공에서 빠지던 것
- **모서리 가공 질량 반영** — 필렛이 STEP 엔 있고 질량엔 없던 것
- **civil 안전검토 신설** · **flanged_fitting 미도달 해소**

### 산출물
- 패키지에 **`model.step`**(CAD 로 열리는 파일이 **하나도 없었다**) · `00_안내.html` · `summary.json`
- **INFO 배지 오표기** — 끼워맞춤에 「단면력 산출」이 붙던 것
- **정밀도 3종** — 관례값 `H/12` · 부동소수 잔재 · 무리수 `≈`

### AI 경로
- 프롬프트 어휘 **9종 → 38종**(단일 소스) · `TYPE_LIST` 의 `undefined` 18종
- `thinkingBudget` (MAX_TOKENS) · thinking 필수 모델 400 폴백
- 어셈블리 스키마가 **키를 떨구던** 문제 → 타입별 `TYPE_SCHEMAS` 재추출
- 도면 판독 **결측 탐지**(파싱 성공 ≠ 판독 성공)

## 5. 내가 틀렸던 것 (전부 실측으로 정정)

| # | 판단 | 실제 |
|---|---|---|
| 1 | 「B-스플라인은 제어점 없이 근사 = 지어내기」 | 파일이 **차수·제어점·노트를 다 갖고 있다** |
| 2 | 타원 새그를 **작은** 반축으로 | 큰 반축이 지배(`a·Δt²/8`) — **정확도 과고지**가 될 뻔 |
| 3 | 「양쪽 캡 `.T.` 는 거부해야」 | 평행 평면 2장은 부호 없이도 두께가 확정된다 |
| 4 | 「임포트가 1/35 로 안 된다」 | 주력 경로는 **35/35 성공** — 문제는 충실도 |
| 5 | 「OCCT 경로가 필요하다」 | **이미 리포 안에 있었다** |

## 6. 규칙으로 굳힌 것

- **비율만 보지 않는다** — `분모`·`apiErrors`·`타입 분류`를 함께 읽는다.
  분모가 줄어든 100% 는 개선이 아니라 선택 편향이다.
- **측정에도 예산이 있다** — 넘으면 측정이 대상을 망가뜨린다.
- **측정 도구를 먼저 의심한다** — 비율이 물리적으로 불가능하면 도구가 틀린 것이다.
- **테스트가 틀린 값을 지키고 있을 수 있다** — 고칠 때마다 진값을 직접 계산해 대조한다.
- **가정을 제품에 맞추지 않는다** — 실측이 가정과 다르면 테스트를 고친다.
- **반올림이 답이 아니다** — 값을 줄이면 관례값이라는 사실이 사라진다. 표시만 바꾼다.
- **`railway up` 의 종료코드·빌드 성공은 배포 확인이 아니다** — 응답 내용으로 본다.
