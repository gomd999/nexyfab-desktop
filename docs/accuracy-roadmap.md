## 축별 진단 (현재 강점 → 남은 약점)

### A. 기하 일치(형상이 수치와 맞는가)
- 있음: 결정론 게이트·auditDims(회전체 face-probe)·역투영 diff(§8-③)·intentToRecordMeasure
- 약점: **라운드트립 정합이 어셈블리 전수 아님** — STEP 산출물이 폐형 예측(질량·AABB)과
  일치하는지 자동 대조가 단품/일부에만.
- 항목 **A1(최우선)**: 어셈블리 STEP 라운드트립 게이트 — intentToStep → 재임포트 →
  부피·AABB 재측정 ↔ partVolume 폐형 합계 대조(±밴드 명시). 도서 패키지에 결과 동봉.

### B. 간섭/지지 판정(과탐도 과소탐도 없는가)
- 있음: AABB + 폐형 정밀규칙 12종(보어 내포·체결·매입·방위각…) + OBB-SAT(box쌍)
- 약점: 회전 revolve·사면·메시 일반쌍은 **보수(과탐 유지)** — 정밀규칙 없는 조합은 오탐.
- 항목 **B1**: 의심쌍 2차 메시 부울 — 정밀규칙 미적용 겹침쌍만 openscad
  `intersection()` 부피>ε 판정(실기하 — 회전·사면·자유곡면 전부 정확). 페어당 수백 ms,
  의심쌍 한정이라 감당.

### C. 표시·STEP 실형상(근사 프록시 잔재)
- 해소됨: pipe_reducer(원뿔대)·revolve 실형상·mesh 폴리헤드론
- 잔재 인벤토리: coil_spring=원통 프록시 · spur_gear 이빨(SCAD gearPoly 는 실형상,
  composeIntent 는?) · hex_bolt 머리(육각 extrude ✓ 확인) · 대형 mesh AABB 폴백(20k↑)
- 항목 **C1**: 프록시 전수 인벤토리 표 작성(자동 — 어휘별 SCAD/intent/STEP 3열 대조
  스크립트) → 실형상화 우선순위. C2: coil_spring 헬릭스 스윕(파라메트릭 — STEP 은
  세그먼트 근사 명시).

### D. 이미지/도면 판독
- 있음: two-stage 분류→치수, confidence 게이트, 사진=형태만
- 약점: 판독 결과의 **역검증 부재** — 추출 형상을 도면에 재투영해 잔차를 재는 §8-③이
  텍스트 경로에만 배선.
- 항목 **D1**: extract 경로에 역투영 diff 자동(추출 intent → 정투영 → 원본 이미지
  윤곽과 IoU/치수 잔차 — 낮으면 신뢰도 강등·되묻기). D2: 멀티뷰 모순 검출(정면/측면
  공유 치수 불일치=정직 거부).

### E. 도면(GA) 투영 충실도
- 있음: 완성도 체크리스트 9종·은선·밸룬·단면
- 약점: 투영이 AABB 사각 — 회전 부품·경사 부재 실루엣 근사(명시돼 있음).
- 항목 **E1**: composeIntent 기반 실윤곽 투영(실린더=사영 타원/직사각, box 회전=OBB
  꼭짓점 투영 — HLR 전 단계의 중간 충실도). E2: visual-golden 확대(제트·SWRO·RC보
  골든 스크린샷 회귀).

### F. 표준·수치 정합
- 있음: std-snap 감사(보고 전용)·BOM 발주 규격
- 항목 **F1**: 스냅 적용 모드(옵션 — 게이트 통과 시 좌표까지 스냅, 기본은 보고 유지).
  **F2 = R2-⑪**(T슬롯·SKF 베어링 표 — 표준 카탈로그 확장이 곧 정확도).

### G. AI 이해층 안전
- 있음: 게이트+교정 1회+대상 외 불변 코드 보장
- 항목 **G1**: edit-part 패치 자연어 재서술 확인 스텝(옵션 — "length 300→500 로
  해석했습니다" 프리뷰, 원클릭 적용). 저신뢰 되묻기.
