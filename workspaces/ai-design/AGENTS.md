# AI Design workspace

Own model providers, prompting, design orchestration, refinement, and AI design
flows registered for this scope.

- Work only on `scope/ai-design`.
- Treat shared paths as integration-owned.
- Do not edit CAD kernel or exact geometry implementations directly.
- Exchange CAD requests and results through versioned packages and artifacts.
- Run `npm run workspace:check -- ai-design` before handoff.
- Update `CURRENT.md` and create an immutable file under `HANDOFFS/` at handoff.
