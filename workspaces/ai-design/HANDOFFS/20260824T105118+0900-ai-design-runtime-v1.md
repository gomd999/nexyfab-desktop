## Implemented runtime producer

### `AiDesignWorkspaceSessionV1`

Source: `src/lib/ai/aiDesignWorkspaceSession.ts`

- Optimistic session revision and idempotent event replay.
- Bounded append-only audit with before/after revisions and timestamps.
- Checkpoint and workflow identity/revision bindings.
- Serializable snapshots, integrity digest, semantic validation, and bounded
  undo/redo for reversible AI-owned session/view changes.
- Precision CAD commit/receipt events may be recorded, but cannot be marked
  reversible or placed in the undo stack.
- Secret-like keys, raw geometry bytes, non-finite values, excessive depth,
  arrays, keys, and strings fail closed.
- Cancellation and recovery identities remain explicit.

### Multimodal input adapters

Source: `src/lib/ai/aiDesignInputAdapter.ts`

- Normalizes `text`, `image`, `sketch`, `drawing_2d`, and `selection_3d` into
  `DesignIntentCheckpointV1` fragments.
- Separates source hash from the common project-revision content hash so
  distinct sources can be composed without losing revision binding.
- Validates IDs, SHA-256, MIME, declared size, field count, serialization
  bounds, provenance, rights, and license evidence.
- OCR, vision, and drawing-parser results remain AI assumptions until
  confirmed; they cannot become imported authority through a client flag.
- `cm`, `m`, `in`, and `rad` values and numeric tolerances are converted to
  canonical `mm`/`deg` values rather than only relabeled.
- Unknown/prohibited rights, raw bytes, secret-like keys, invalid units,
  non-finite values, and oversized values block checkpoint creation.

### Generation orchestrator

Source: `src/lib/ai/aiDesignGenerationOrchestrator.ts`

- Runs real named stages: understanding, planning, candidate generation, and
  candidate validation.
- Progress reports completed/total stages and current label; it deliberately
  emits no invented percentage.
- Model selection receipts are bound to the run. Simple execution selects Luna
  when entitlement/capability policy permits.
- Runtime fallback records from/to model, stable reason, and time. Previously
  attempted models are excluded so fallback cannot oscillate.
- Stage input/output digests, producer, attempt, codes, and times are recorded.
- Stale revisions, malformed evidence, timeouts, retry limit, cancellation,
  and exact-stage resume fail closed.
- Worker exception text is reduced to a stable error code so provider secrets
  or private response text cannot enter persisted state.
- An injected worker is the execution boundary; provider adapters do not gain
  CAD authority through this contract.

### Candidate and gauge UX

Source: `src/lib/ai/aiDesignComparisonGaugeUx.ts`

- Maximum three-candidate matrix across requirements, dimensions,
  manufacturing, and cost.
- Metric status and bound source-evidence status are shown separately; the
  combined cell uses the worst-case status.
- Changed/unchanged is only calculated for comparable verified values.
- Cost remains estimated unless both the metric and its bound evidence are
  verified and the producer explicitly marks it non-estimated.
- Partial apply exposes stale, scope, failed, and incomplete-verification
  blockers.
- Gauge UX adds deterministic primary selection, fine/coarse steps,
  local/global frame, axis lock, numeric fallback, touch increments, preflight
  warnings, 44 px minimum touch target, reduced motion, and non-color labels.

### Unified workspace runtime and UI effects

Sources:

- `src/lib/ai/aiDesignWorkspaceRuntime.ts`
- `src/lib/ai/aiDesignScreenActionDispatcher.ts`

The immutable runtime coordinates checkpoint, workflow, generation, candidate,
gauge, model receipt, session snapshot, and revision token. Its action
dispatcher provides optimistic revision checks and idempotent action IDs for
understanding, input resolution, generation, fallback, retry, publication,
selection, gauge edit, cancellation/resume, and Precision request.

The screen dispatcher converts every rendered `AiDesignScreenActionId` to one
bounded effect owned by `local-ui`, `ai-design-runtime`, or `precision-cad`.
Preview is non-persistent, exact requests require explicit commit, and every
effect promises to preserve CAD selection when the AI model changes.

### Runtime persistence API

Sources:

- `src/lib/ai/aiDesignWorkspaceRuntimeStore.ts`
- `src/app/api/nexyfab/ai-design/workspace-session/route.ts`

`GET|POST /api/nexyfab/ai-design/workspace-session` requires authentication,
project access, bounded identity/body validation, POST origin validation, and
rate limiting. The store applies a 1 MiB limit, canonical server SHA-256,
owner/project/session binding, TTL, and compare-and-swap runtime revision.

Redis or in-memory storage is not accepted as commercial release persistence.
When `NEXYFAB_COMMERCIAL_MODE=1`, the store fails closed with
`AI_DESIGN_WORKSPACE_POSTGRES_AUTHORITATIVE_REQUIRED`. The required PostgreSQL
schema/migration is integration-owned and is therefore a downstream task, not
silently added from this scope.

### Privacy-safe telemetry

Source: `src/lib/ai/aiDesignRuntimeTelemetry.ts`

- Allowlisted operational event kinds, codes, counts, and attributes only.
- Project/session identities are pseudonymized.
- Prompts, messages, text content, files, images, geometry, bytes, and secret
  fields are rejected.
- Events explicitly declare no user content, no geometry, and no exact-geometry
  authority.

## Copyright and authority boundary

The implementation uses general design-process and UI interaction concepts
only. It does not copy manuals, encyclopedia prose, diagrams, tables, formulas,
examples, UI artwork, or third-party geometry. Every source retains provenance
and rights metadata; unknown or prohibited rights fail closed. A
`copyrightSafe` flag is a workflow policy, not third-party license proof. Exact
geometry, topology, kernel execution, and manufacturing release remain
Precision CAD or other authoritative verifier responsibility.
