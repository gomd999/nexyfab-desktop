The authenticated private `GET /api/nexyfab/ai-design/workspace-session/complex-workspace` response now returns:

## Implemented contracts

### Chat-first workspace

- `src/lib/ai/aiDesignChatFirstWorkspaceContract.ts`
- Accepts text, 2D drawing, image/sketch, and existing 3D inputs.
- Covers intake, understanding, generation, candidate review, edit, Precision handoff, and recovery stages.
- Provides Korean first-use starter cards and English fallback.
- Keeps one deterministic next recommended action with a short explanation.
- Desktop uses a visual split workspace with chat support; mobile starts in chat and opens the canvas on demand.

### Executable conversation cards

- `src/lib/ai/aiDesignChatActionCards.ts`
- Cards cover input, clarification, generation, candidate selection/comparison, change preview/apply/reject, AI-view undo/redo, recovery, and Precision request/evidence inspection.
- Every action is mapped to exactly one boundary: `local-ui`, `ai-design-runtime`, or `precision-cad`.
- Preview is non-persistent. Concept apply is explicit and session-only. Exact CAD requests require explicit confirmation.
- Browser-authored exact PASS and manufacturing release remain impossible.
- Stale revisions, disabled actions, missing references, multiple primary CTAs, and confirmation-policy drift fail closed.

### Synchronized 2D and 3D

- `src/lib/ai/aiDesign2d3dSync.ts`
- Stable reference kinds: drawing entity, dimension, structure node, feature, and parameter.
- Modes: `2d`, `3d`, and `split`.
- Supports linked selection, 2D-change to 3D-impact preview, and 3D-gauge to 2D-drawing-update preview.
- Missing, invalid, or ambiguous mappings return `NEEDS_INPUT`; no guessed association is committed.
- Cross-domain mapping direction and bounded mapping sizes are validated.
- AI Design remains `ai_design_concept_preview` with `commitAllowed: false`.

### Unified V9 consumption model

- `src/lib/ai/aiDesignUnifiedWorkspaceV9.ts`
- Composes V1-V8 workspace state into one V9 response.
- Desktop contract: chat rail plus synchronized 2D/3D split canvas and inspector.
- Mobile contract: chat-first, full-screen 2D/3D tabs, modal bottom sheet, sticky preview/apply/cancel, 44 px targets, and one-finger edit/two-finger camera arbitration.
- Model ID, selection status, fallback/change explanation, revisions, recovery, and trust state stay in one view-model.
- Until Precision CAD supplies stable bidirectional renderer mappings, `canvas.mappingStatus` is `awaiting_precision_binding` and sync actions fail closed.

### Usability and scenario evidence

- `src/lib/ai/aiDesignUsabilityEvidence.ts`
- Records bounded timings/counters only: first input, completion, help opens, invalid actions, and recovery count.
- Does not collect prompt text, drawing bytes, geometry, personal data, or raw project identity.
- Its outcome is explicitly `heuristic_only_not_release_evidence`.
- `src/lib/ai/aiDesignChatFirstScenariosV9.ts` defines ordered evidence runs for:
  1. `text-to-synchronized-2d-3d`
  2. `drawing-to-3d-ambiguity-resolution`
  3. `existing-3d-text-edit-updates-2d`
  4. `mobile-interruption-recovery`
  5. `model-fallback-preserves-selection`
- A headless scenario cannot become PASS when renderer or Precision evidence is required but not attached.

## Precision CAD and actual UI consumer contract

No Precision CAD file was changed. After integration, the consumer must:

1. Bind `unified.chat` and `unified.cards` to the existing chat screen while keeping chat as the workflow spine.
2. Bind `unified.canvas.availableModes` to real `2d`, `3d`, and desktop `split` surfaces.
3. Produce bidirectional stable mappings:
   - 2D `drawing_entity` or `dimension` -> 3D `structure_node`, `feature`, or `parameter`
   - 3D `structure_node`, `feature`, or `parameter` -> 2D `drawing_entity` or `dimension`
4. Preserve the same project/session/runtime revision and stable selection IDs when changing chat/model/view mode.
5. Render gauge edits as preview in both views. Do not persist exact geometry before an explicit Precision CAD request.
6. Return signed, server-verified Precision receipts. The browser must never author PASS.
7. Keep exact CAD commits and receipts outside AI-view undo/redo.
