# Precision CAD workspace

Own exact geometry, CAD authoring, feature history, drawings, CAD workers, and
discipline-specific CAD implementations registered for this scope.

- Work only on `scope/precision-cad`.
- Treat shared paths as integration-owned.
- Do not edit AI provider or orchestration implementations directly.
- Exchange cross-scope data through versioned packages and artifacts.
- Run `npm run workspace:check -- precision-cad` before handoff.
- Update `CURRENT.md` and create an immutable file under `HANDOFFS/` at handoff.
