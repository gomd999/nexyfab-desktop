## 콘텐츠 #1 — 메이크올 / 클리앙 게시글

**제목**: 브라우저에서 3D 설계 → 그대로 한국 가공업체로 발주 (NexyFab)

> 안녕하세요. 메이커 / 1인 개발자 분들을 위한 web CAD 서비스를 만들고 있어 공유드립니다.
>
> **NexyFab** (https://nexyfab.com) 차별점:
>
> 1. **OpenSCAD 양방향**
>    - GUI에서 sketch + extrude로 그리면 OpenSCAD 코드가 자동 생성됨
>    - 거꾸로 OpenSCAD 코드를 붙여 넣으면 GUI 피처 트리로 변환 (cube / cylinder / sphere + translate)
>    - 매개변수화된 부품을 코드로 관리하다 GUI에서 미세 조정 가능
>
> 2. **한국 파트너 가공업체 즉시 발주**
>    - 설계 끝나면 같은 화면에서 견적 요청
>    - CNC / 판금 / 사출 / 3D 프린트 한 곳에서 RFQ
>    - 광고용 매칭이 아니라 다차원 평가 (납기/품질/응답속도/소통 분리 표시)
>
> 3. **AI 설계 보조 — 정직하게**
>    - "5cm 큐브에 8mm 구멍" 같은 자연어 입력 → STL
>    - AI 출력은 "초안" 워터마크, 발주 전 사용자 검증 필수 명시
>    - DFM 자동 게이트 (3D 프린트: 0.4-0.8mm 벽두께, CNC: tool clearance, 판금: bend radius)
>
> **무료 1프로젝트 + Pro 2번째 프로젝트** (memory `nexyfab-freemium` 준수).
>
> 데모 모드에서 가입 없이 풀 워크플로우 체험 가능합니다.
>
> 의견 / 피드백 환영합니다. 댓글이나 nexyfab@nexysys.com.

## 콘텐츠 #3 — 유튜브 메이커 채널 협찬 제안

대상 채널 후보:
- "메이커즈 다이어리" (5만 구독)
- "3D 프린터 코리아" (8만)
- "CNC 매뉴얼" (3만)
- "메이커 다이렉트" (6만)

**제안 패키지**:
- 단순 광고 ❌
- "1인 SaaS 사용해 봤다" 리뷰 형식 → 광고처럼 안 보임
- 1편당 50-150만 원 (구독자 규모별)
- 영상 요건:
  - 실제 워크플로우 시연 (스케치→발주까지)
  - "정직 평가" — 잘 되는 점 + 안 되는 점 둘 다
  - 영상 설명란에 nexyfab.com 링크 + "메이커즈 코드 NF20" (20% Pro 할인)

KPI:
- 영상 1편 → 사이트 방문 100명 → 가입 10명 (10%) → Pro 전환 1명 → ARR 환산 시 손익분기 4-6편
- 안 되면 광고비 burn rate 알람 (memory: ad burn 자동 cutoff)

## 콘텐츠 #4 — 대학 산학협력단 / 학회 학생회 협력

대상:
- 산업디자인학과 (홍대 / 국민대 / 서울대 / 카이스트)
- 기계공학과 (서울대 / 카이스트 / 포항공대)
- 의용공학과 (의료기기 설계 동아리)
- 메이커 동아리 (각 학교)

**제안**:
- 학과 / 동아리 단위로 무료 license (학기 단위)
- 졸업작품 / 캡스톤 디자인에 NexyFab 도입 시 견적 발주까지 무료
- 매년 1회 NexyFab 디자인 콘테스트 (상금 500만 원, 1인 SaaS 예산 한계 고려)
- 졸업생이 회사 도입 시 본인 활용 경험을 통해 채택 확률 ↑

추진 단계:
1. 산업디자인학회 / 메이커페어 부스 (50-200만 원 / 회)
2. 학과 사무실 cold call → 무료 license 제안
3. 학기 시작 전 (3월, 9월) 집중 시기
